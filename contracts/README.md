# contracts

**FE 와 BE 가 같아야 하는 규칙의 단일 출처.**

두 프로젝트는 [의도적으로 분리](../docs/50-decisions/0002-monorepo-be-fe-split.md)돼 있어
서로의 코드를 import 하지 않는다. 그런데 **같아야만 하는 규칙**이 몇 개 있고,
지금까지는 주석으로만("FE 와 같은 규칙이어야 한다") 지켜 왔다 —
갈라져도 아무것도 알려주지 않는다.

이 폴더의 파일은 **데이터**다. 양쪽 테스트가 `fs` 로 읽어 자기 구현과 대조한다.
한쪽이 갈라지면 **그쪽 테스트가 깨진다.**

| 파일 | 무엇이 갈라지면 무엇이 깨지나 |
| --- | --- |
| `slug-cases.json` | 태그·앵커 정규화가 갈라지면 **같은 태그가 두 표기로 저장돼 필터가 무너진다** |
| `tag-namespaces.json` | 고정 어휘가 갈라지면 한쪽이 아는 네임스페이스를 다른 쪽이 자유 태그로 취급한다 |
| `topics.json` | 주제가 갈라지면 FE 가 보낸 `topic` 을 BE 가 400 으로 거부하거나 목록 필터에서 조용히 빠진다 |

**고정 어휘만 여기서 강제한다.** 응답의 *모양*(필드 이름·페이지 여부)은 데이터로
못 잡는다 — 그건 [`FE/**/*.integration.test.ts`](../FE/ARCHITECTURE.md) 가
라이브 BE 를 상대로 확인한다.

## 왜 런타임 공유(모노레포 패키지)가 아닌가

12줄짜리 함수와 목록 하나 때문에 워크스페이스 도구를 들이면
[BE/FE 분리](../docs/50-decisions/0002-monorepo-be-fe-split.md)가 흐려진다.
**계약을 테스트로 강제하는 것**은 이 저장소가 이미 쓰는 방식이다 —
[두 저장소 드라이버가 같은 e2e 를 통과해야 한다](../BE/README.md)와 같은 패턴이다.

## 고칠 때

값을 바꾸면 **양쪽 테스트가 함께 깨진다.** 그게 의도다 —
한쪽만 고치고 넘어갈 수 없게 만드는 것이 이 폴더의 존재 이유다.
