# 라운드와 층

## 라운드

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `rounded-sm` | 4px | 배지, 태그 |
| `rounded-md` | 6px | 버튼, 입력 필드 |
| `rounded-lg` | 8px | 카드 |
| `rounded-xl` | 12px | 큰 패널, 모달 |
| `rounded-2xl` | 16px | 히어로 블록 |
| `rounded-full` | — | 아바타, 필 형태 |

### 규칙

- 한 화면에서 **2~3개 단계만** 쓴다. 다 쓰면 규칙이 없어 보인다
- 중첩될 때 안쪽이 바깥쪽보다 작아야 한다 (카드 `lg` 안의 버튼 `md`)
- 라운드를 크게 하면 친근해지지만 **정보 밀도가 낮아 보인다.** konnect는 정보 서비스라
  과하게 둥글리지 않는다

## 층 (elevation)

```
shadow-e1   미세한 구분        (입력 필드 hover 등)
shadow-e2   카드가 떠 있음      (기본 카드)
shadow-e3   드롭다운·팝오버
shadow-e4   모달
```

### 층은 그림자만으로 만들지 않는다

| 테마 | 주 수단 | 보조 |
| --- | --- | --- |
| 라이트 | 그림자 | 보더 |
| **다크** | **표면 밝기 차** | 그림자(거의 안 보임) |

다크 모드에서 그림자는 검은 배경에 검은 그림자라 사실상 보이지 않는다.
그래서 `surface` → `surface-raised`의 **밝기 차이**로 층을 표현한다.
다크에서 카드가 안 떠 보인다면 그림자를 키울 게 아니라 `bg-surface-raised`를 확인한다.

### 규칙

- 층은 **의미**다. 예쁘라고 쓰지 않는다. 떠 있는 것은 위에 있어야 할 이유가 있어야 한다
- 한 화면에 `e3` 이상이 여러 개면 위계가 무너진 것이다
- 층과 보더를 둘 다 강하게 쓰지 않는다. 하나로 경계를 만든다
