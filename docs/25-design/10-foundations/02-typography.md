# 타이포그래피

## 폰트 스택

```
--font-sans: Geist, "Apple SD Gothic Neo", "Malgun Gothic",
             "Noto Sans KR", ui-sans-serif, system-ui, sans-serif
```

### 왜 한글 폴백이 명시되어 있나

**Geist에는 한글 글리프가 없다.** konnect는 한 문장 안에 한글이 섞이는 것이 관례다:

```
Alien Registration Card (외국인등록증)
```

브라우저는 글리프 단위로 폴백하므로 라틴은 Geist, 한글은 다음 스택에서 렌더된다.
폴백을 명시하지 않으면 OS 기본 산세리프로 떨어져 **자간·굵기가 튄다.**

플랫폼별로 `Apple SD Gothic Neo`(macOS/iOS) → `Malgun Gothic`(Windows) →
`Noto Sans KR`(그 외/설치된 경우) 순으로 잡았다.

> **개선 여지**: 한글 타이포그래피 품질이 중요해지면 Pretendard 같은
> 한글·라틴 통합 폰트를 웹폰트로 얹는 것을 검토한다. 지금은 웹폰트 용량을
> 추가하지 않는 쪽을 택했다(초기 로딩이 검색 유입 이탈에 직결된다).

## 타입 스케일

| 토큰 | 크기 | 행간 | 쓰는 곳 |
| --- | --- | --- | --- |
| `text-xs` | 12px | 18px | 배지, 라벨 |
| `text-sm` | 14px | 22px | 메타 정보, 보조 |
| `text-base` | **16px** | **26px** | **본문** |
| `text-lg` | 18px | 28px | 리드 문단 |
| `text-xl` | 20px | 28px | 카드 제목 |
| `text-2xl` | 24px | 32px | 섹션 제목 |
| `text-3xl` | 30px | 36px | 페이지 제목 |
| `text-4xl` | 36px | 40px | 히어로 |

### 본문 행간이 1.625인 이유

일반적인 본문 행간은 1.5다. konnect는 **1.625**로 더 넉넉하게 잡았다.

- 사용자 다수가 **제2언어로 읽는다.** 훑지 않고 한 줄씩 읽는다 ([원칙 2](../01-principles.md))
- 한글과 라틴이 섞이면 글자 높이가 달라 줄이 빽빽해 보인다
- 행정·법률 내용이라 문장이 길다

### 규칙

- **본문 최소 16px.** 12px는 메타 정보 전용이다. 본문에 쓰지 않는다
- 한 줄 길이는 **약 70자**로 제한한다 (`max-w-[70ch]` 또는 컨테이너 폭)
- 제목 위계는 크기만이 아니라 **굵기와 여백**으로 함께 만든다
- `text-*`는 크기와 행간을 함께 바꾼다. 행간만 따로 덮어쓰지 않는다

## 굵기

| 용도 | 굵기 |
| --- | --- |
| 본문 | 400 |
| 강조 (`<strong>`) | 600 |
| 제목 | 600~700 |

얇은 굵기(300 이하)는 쓰지 않는다 — 대비가 떨어져 가독성을 해친다.
