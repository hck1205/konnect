# 간격과 레이아웃

## 간격 스케일

**4px 기준**의 배수 스케일을 쓴다 (Tailwind 기본값 유지).

```
1 = 4px    2 = 8px    3 = 12px   4 = 16px
6 = 24px   8 = 32px   12 = 48px  16 = 64px
```

### 규칙

- **임의 값(`p-[13px]`)을 쓰지 않는다.** 스케일에 없으면 스케일이 맞는지 먼저 의심한다
- 홀수 단계(5, 7, 9…)는 가급적 피한다. 리듬이 깨진다
- 관련된 것은 가깝게, 관련 없는 것은 멀게 — **근접성이 곧 그룹 표시**다

### 자주 쓰는 조합

| 관계 | 간격 |
| --- | --- |
| 아이콘 ↔ 레이블 | `gap-2` (8px) |
| 폼 필드 사이 | `gap-4` (16px) |
| 카드 내부 패딩 | `p-4`~`p-6` |
| 섹션 사이 | `gap-8`~`gap-12` |
| 페이지 상하 여백 | `py-12`~`py-16` |

## 본문 폭

| 콘텐츠 | 최대 폭 |
| --- | --- |
| 읽기 중심(질문 상세, 가이드) | **약 70자** — `max-w-3xl` 근처 |
| 목록·피드 | `max-w-4xl` |
| 대시보드·관리 화면 | 제한 없음 |

읽기 폭을 제한하는 이유는 [원칙 2](../01-principles.md)와 같다 — 긴 줄은 다음 줄을
찾기 어렵고, 제2언어 독자에게 부담이 크다.

## 브레이크포인트

Tailwind 기본값을 그대로 쓴다.

| 이름 | 최소 폭 |
| --- | --- |
| `sm` | 640px |
| `md` | 768px |
| `lg` | 1024px |
| `xl` | 1280px |
| `2xl` | 1536px |

### 모바일 우선

기본 스타일이 모바일이고, `md:` 이상에서 넓혀 간다.
타깃 사용자 상당수가 **입국 직후 모바일로** 접근한다(노트북을 아직 못 쓰거나, 이동 중이다).

## 터치 타깃

인터랙티브 요소의 최소 크기는 **44×44px**다.
시각적으로 작아 보여도 패딩이나 `::before`로 히트 영역을 확보한다.
