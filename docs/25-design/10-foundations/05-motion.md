# 모션

## 원칙: 절제

konnect는 **정보를 찾으러 온 사람**이 쓰는 서비스다 ([원칙 1](../01-principles.md)).
모션은 즐거움이 아니라 **상태 변화를 이해시키는 도구**로만 쓴다.

## 지속 시간

| 용도 | 시간 |
| --- | --- |
| 색·투명도 변화 (hover, focus) | 100~150ms |
| 작은 요소 등장/퇴장 (툴팁, 배지) | 150ms |
| 드롭다운·팝오버 | 200ms |
| 모달·시트 | 250~300ms |

**300ms를 넘기지 않는다.** 그 이상은 느리게 느껴진다.

## 이징

| 토큰 | 용도 |
| --- | --- |
| `--ease-out-soft` | 등장 — 빠르게 나타나 부드럽게 정착 |
| `--ease-in-out-soft` | 이동·크기 변화 |

`linear`는 쓰지 않는다(기계적으로 보인다). 튀는 이징(bounce, elastic)도 쓰지 않는다.

## 반드시 지킬 것

### `prefers-reduced-motion`

`globals.css`에 전역으로 적용되어 있다. 사용자가 시스템에서 모션 감소를 켜면
모든 애니메이션·트랜지션이 사실상 즉시 끝난다.

이것은 **선택 사항이 아니다.** 전정기관 장애가 있는 사용자에게 모션은
어지럼증과 메스꺼움을 유발한다.

컴포넌트가 JS로 애니메이션을 구현한다면 이 설정을 **직접 확인해야 한다** —
CSS 전역 규칙이 JS 애니메이션까지 막아주지는 않는다.

```ts
const reduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
```

## 하지 말 것

- 페이지 전환 애니메이션 (검색 유입자가 상세에 바로 착지한다 — 전환이 없다).
  View Transitions API를 쓰지 않기로 한 것도 같은 이유다
  → [네이티브 플랫폼 우선](./08-native-platform.md#쓰지-않기로-한-것)
- 스크롤 연동 애니메이션 (읽기를 방해한다)
- 로딩 스피너를 200ms 미만에 띄우기 (깜빡임만 남는다)
- 자동 재생되는 캐러셀
