## 구현 위치

토큰의 **실제 값은 코드에 있다.** 이 문서는 값을 복사해 두지 않는다(복사본은 반드시 어긋난다).

```
FE/src/app/globals.css     ← 토큰의 단일 출처
FE/src/components/         ← 컴포넌트 (카테고리별)
FE/.ladle/                 ← 스토리 설정
```

컴포넌트 폴더 규약은 [FE/ARCHITECTURE.md](../../FE/ARCHITECTURE.md) 참고.
