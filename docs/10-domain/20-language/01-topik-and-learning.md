# 한국어 학습과 시험

## 이 영역의 질문 유형

| 유형 | 예 | 답의 성격 |
| --- | --- | --- |
| 요건 | "이 학교/비자는 몇 급이 필요한가?" | 기관마다 달라 **출처 링크가 답**이다 |
| 선택 | "어학원 vs 대학 어학당 vs 독학?" | 경험 비교 — 후기가 답이다 |
| 방법 | "6개월 만에 3급 가능한가?" | 사례 축적이 답이다 |
| 실무 | "시험 접수는 어떻게 하나?" | 절차 — 가이드로 승격 대상 |

## 우리가 하는 것 / 안 하는 것

- **한다**: 경험 비교, 학원/어학당 후기, 학습 경로 사례, 접수 절차 가이드
- **안 한다**: 한국어 강의 제공, 교재 판매, 레벨 테스트 자체 운영
  → 우리는 학습 서비스가 아니다 ([비범위](../../00-overview/04-scope-and-non-goals.md))

## 다른 영역과의 연결

- **비자**: 일부 체류자격·전환에서 한국어 능력이 요건이 된다 → `visa:*` 태그와 교차
- **학교**: 입학 요건으로 자주 걸린다 → [30-education](../30-education/)
- **취업**: 직무별로 요구 수준이 크게 다르다 → [50-work-career](../50-work-career/)

이 교차성 때문에 어학은 **독립 게시판보다 태그로** 다루는 편이 맞을 수 있다(열린 질문).

## 열린 질문

- 어학을 별도 게시판으로 둘 것인가, `topic:language` 태그로만 둘 것인가?
- 학원/어학당 **후기에 평점**을 붙일 것인가? 붙이면 분쟁·명예훼손 리스크가 생긴다.
