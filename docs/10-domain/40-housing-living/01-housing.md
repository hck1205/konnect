# 주거

## 왜 리스크가 높은가 (R1)

- **보증금**이 크다. 전세는 수천만~수억 원 단위가 오간다.
- 계약서가 **한국어**다. 못 읽고 서명하는 상황이 실제로 발생한다.
- 한국 특유의 제도(전세, 확정일자, 등기부등본 확인)가 **다른 나라에 대응물이 없다**.
  "몰라서 당한다"가 아니라 "존재를 몰라서 확인조차 못 한다"에 가깝다.

→ [콘텐츠·리스크 정책](../10-visa-immigration/03-content-and-risk-policy.md)의 R1로 다룬다.

## 다루는 주제

| 주제 | 성격 |
| --- | --- |
| 임대 방식 비교 (전세 / 월세 / 반전세 / 고시원 / 셰어하우스) | 개념 설명 — 가이드 |
| 집 구하는 경로 (부동산, 앱, 학교 게시판, 커뮤니티) | 경험 비교 |
| 계약 전 확인 항목 | **체크리스트** — 이 영역 최우선 콘텐츠 |
| 보증금 보호 | R1 — 출처 링크 필수 |
| 지역·시세 감각 | 경험 공유, `region:*` 태그 |
| 이사·퇴거·원상복구 분쟁 | 사례 축적 |

## 우리가 하지 않는 것

- **중개 행위** — 매물 등록/알선을 하지 않는다. 라이선스와 책임 문제 ([비범위](../../00-overview/04-scope-and-non-goals.md))
- **계약서 검토 대행** — 개인 간 도움은 커뮤니티에서 일어날 수 있으나, 서비스가 보증하지 않는다
- 특정 부동산/중개인 **추천 광고**

## 제품에 주는 힌트

- "계약 전 확인 항목" 체크리스트는 **인쇄/저장 가치가 있는 형태**여야 한다(오프라인에서 쓴다).
- 한국어 계약 용어는 **원문 + 설명 병기** 패턴이 필요하다 → [i18n 전략](../../30-architecture/06-i18n-strategy.md)

## 열린 질문

- 매물 정보를 **아예 다루지 않을 것인가**, "구합니다/내놓습니다" 게시판 정도는 열 것인가?
  (열면 사기 리스크와 모더레이션 부담이 급증한다 — 현재는 열지 않는 쪽)
