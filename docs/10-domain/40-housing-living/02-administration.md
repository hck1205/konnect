# 생활 행정

## 이 영역의 본질: 의존 순서

각 항목이 서로의 **선행조건**이라 순서를 모르면 며칠씩 낭비한다.
초기 정착의 좌절이 대부분 여기서 나온다 ([문제 정의 P6](../../00-overview/02-problem-statement.md)).

```
입국
 └─ 외국인등록(ARC) ──┬─→ 은행 계좌
                      ├─→ 휴대폰 개통(본인확인)
                      ├─→ 건강보험
                      └─→ 각종 온라인 본인인증
```

> 위 그림은 **의존 관계의 개념도**이지 정확한 절차도가 아니다. 실제 요건은 기관·시점마다
> 다르므로, 구체 절차는 출처 링크를 단 가이드 콘텐츠로 다룬다.

## 다루는 항목

| 항목 | 왜 어려운가 |
| --- | --- |
| 외국인등록(ARC) | 예약 경쟁, 서류 준비, 지역별 차이 |
| 은행 계좌 | 지점마다 요구 서류가 다르다는 경험이 많다 |
| 휴대폰 | 본인확인 체계가 ARC에 묶여 있다 |
| 건강보험 | 가입 시점·자격이 체류자격에 따라 갈린다 |
| 온라인 본인인증 | 외국인이 막히는 대표 지점(공동인증서, 통신사 인증) |
| 교통카드·운전면허 | 상대적으로 쉬움 (R3) |
| 세금 | 소득이 있으면 복잡해진다 (R1) |

## 제품에 주는 힌트

- 이 영역이 **"도착 직후 체크리스트"의 본체**다. MVP에서 가장 먼저 만들 콘텐츠 후보.
- 지역차가 크므로 `region:*` 태그가 실제로 유효한 몇 안 되는 영역이다.
- "나는 여기서 이 서류로 됐다"는 **사례 데이터**가 공식 안내보다 실용적일 때가 많다 →
  단, 개인 사례임을 반드시 구분 표시한다(R1 규칙).
