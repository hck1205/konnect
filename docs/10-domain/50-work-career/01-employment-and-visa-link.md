# 취업과 체류자격

## 이 영역이 어려운 이유

한국에서 외국인의 취업은 **체류자격과 묶여 있다.** 직장이 곧 체류 근거인 경우가 많아,
"이직"이 단순한 커리어 결정이 아니라 **체류 리스크**가 된다.

이 결합 때문에 취업 질문의 상당수가 실제로는 비자 질문이다 →
`topic:work` + `visa:*` **교차 태그**가 이 영역의 기본형이다.

## 질문이 몰리는 지점

| 상황 | 질문 |
| --- | --- |
| 졸업 예정 (G → D) | 학생 비자에서 취업 비자로 어떻게 넘어가나 |
| 구직 중 | 스폰서를 해 주는 회사를 어떻게 찾나 |
| 오퍼 수령 | 계약 조건을 어떻게 봐야 하나, 연봉 요건이 있나 |
| 재직 중 | 부업/프리랜스가 가능한가 |
| 이직 | 스폰서가 바뀌면 절차가 뭔가, 공백 기간은 괜찮나 |
| 퇴사/해고 | 체류에 무슨 일이 생기나 (**가장 급박한 질문**) |

## 리스크 등급

**R1.** 잘못된 답이 체류자격 상실로 이어질 수 있다.
특히 "퇴사 후 며칠 안에 무엇을 해야 하는가" 류는 기한이 걸려 있어 오답의 피해가 즉각적이다.

## 우리가 하지 않는 것

- **채용 공고 게시 / 구인구직 매칭** — 초기 비범위.
  (열면 사기·허위 공고 모더레이션 부담이 크고, 스폰서 관련 분쟁에 서비스가 끼게 된다)
- 연봉 협상 대행, 노무 자문

## 다루는 것

- 경험 공유: "나는 이 경로로 전환했다"
- 계약서에서 확인할 항목 체크리스트(일반론 수준 + 출처 링크)
- 산업/직군별 현실 감각 (IT, 교육, 제조 등)

## 열린 질문

- 익명성: 재직 중 회사 이야기는 **신원 노출 위험**이 크다. 익명 게시를 허용할 것인가?
  허용하면 모더레이션이 어려워지고, 안 하면 이 영역 글이 안 올라온다.
- 회사명 언급을 허용할 것인가? (비방·명예훼손 경계)
