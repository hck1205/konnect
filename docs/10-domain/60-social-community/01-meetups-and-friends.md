# 밋업과 교류

## 왜 필요한가

정보 커뮤니티만으로는 **재방문 동기가 약하다.** 문제가 풀리면 떠난다.
사람이 연결되면 남는다 — 커뮤니티의 지속성은 결국 관계에서 나온다.

동시에 이건 사용자가 실제로 겪는 고통이기도 하다. 특히 정착 초기 사용자(B·C·D).

## 형태

| 형태 | 안전 리스크 | 우선순위 |
| --- | --- | --- |
| **공개 그룹 밋업** (여러 명, 공개 장소) | 낮음 | 1 |
| 관심사 기반 소모임 (운동, 스터디, 취미) | 중간 | 2 |
| 지역 기반 모임 (`region:*`) | 중간 | 2 |
| 1:1 언어교환 | **높음** | 3 — [언어교환](../20-language/02-language-exchange.md) 참고 |
| 1:1 DM | 높음 | 비범위(초기) |

**그룹부터 시작한다.** 1:1은 안전 장치가 갖춰진 뒤에 연다.

## 최소 기능

- 밋업 등록(제목, 일시, 장소, 정원, 언어)
- 참가 신청 / 취소
- 주최자 프로필 확인
- 신고

## 열린 질문

- 노쇼 문제를 어떻게 다룰 것인가? (평판에 반영? 참가 이력 표시?)
- 온라인 밋업을 포함할 것인가? (아직 지역에 연고가 없는 사용자에게는 이쪽이 유일한 접점)
- 유료 모임을 허용할 것인가? → 결제는 [비범위](../../00-overview/04-scope-and-non-goals.md)이므로 현재는 불가
