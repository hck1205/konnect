# 용어집

문서·코드·UI가 같은 대상을 같은 단어로 부르기 위한 사전.
**영문 용어가 코드/UI의 기준**이고, 한국어는 문서용 대응어다.

## 제품 용어

| 영문 (코드/UI) | 한국어 | 정의 |
| --- | --- | --- |
| `Question` | 질문 | 답을 구하는 글. 채택 답변을 가질 수 있다 |
| `Answer` | 답변 | 질문에 대한 응답. 댓글과 구분된다 |
| `Post` | 게시글 | 게시판에 쓰는 일반 글(질문이 아닌 것) |
| `Guide` | 가이드 | 여러 Q&A에서 승격된, 여러 사람이 편집하는 문서 |
| `Board` | 게시판 | 주제별 글 묶음 |
| `Topic` | 주제 | 도메인 분류(비자·주거·어학 …). `10-domain`의 카테고리와 대응 |
| `Tag` | 태그 | 맥락 라벨(`visa:d-2`, `region:seoul`, `school:snu` …) |
| `Checklist` | 체크리스트 | 시점별 할 일 묶음 |
| `Meetup` | 밋업 | 오프라인/온라인 모임 |
| `Reputation` | 평판 | 기여로 쌓이는 신뢰 점수 |
| `Verified answer` | 채택 답변 | 질문자가 고른 답변 |
| `Freshness` | 최신성 | "이 정보가 언제 마지막으로 확인되었는가" |

## 도메인 용어 (한국 행정)

혼동이 잦은 것만. 상세는 [10-domain](../10-domain/)에 있다.

| 용어 | 설명 |
| --- | --- |
| ARC (Alien Registration Card) | 외국인등록증. 국내 거의 모든 절차의 선행조건 |
| Status of stay | 체류자격. D-2, E-7 등 |
| Period of stay | 체류기간. 자격과 별개로 만료일이 있다 |
| Extension | 체류기간 연장 |
| Change of status | 체류자격 변경 (예: D-2 → E-7) |
| Sponsor | 비자를 보증하는 소속(학교/회사) |
| Jeonse (전세) | 보증금만 맡기고 월세가 없는 임대 방식 |
| Wolse (월세) | 보증금 + 월 임대료 방식 |
| TOPIK | 한국어능력시험 |
