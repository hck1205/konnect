# 문제 정의

## 사용자가 실제로 막히는 지점

| # | 상황 | 왜 어려운가 |
| --- | --- | --- |
| P1 | 내 상황에 맞는 **정확한 절차**를 모른다 | 공식 안내는 일반론이고, 예외가 많고, 한국어다 |
| P2 | 정보가 **최신인지** 알 수 없다 | 블로그 글의 절차가 2년 전 기준인지 알 방법이 없다 |
| P3 | **누구에게 물어야 할지** 모른다 | 같은 처지의 사람을 만날 통로가 없다 |
| P4 | 물어볼 곳이 있어도 **검색이 안 된다** | 답이 카톡방·디스코드에 있어 축적되지 않는다 |
| P5 | 답이 **내 언어로** 없다 | 번역기로 읽으면 행정 용어에서 의미가 깨진다 |
| P6 | 초기 정착이 **동시다발**이다 | 비자·주거·통장·휴대폰·보험이 서로 선행조건으로 엮여 순서를 모른다 |
| P7 | **사람을 못 만난다** | 정보 문제를 다 풀어도 고립은 남는다 |

## 기존 대안과 한계

| 대안 | 강점 | 한계 |
| --- | --- | --- |
| 정부/기관 공식 사이트 (Hi Korea 등) | 정확·권위 | 절차 중심, 내 사례 매칭 어려움, 언어 장벽 |
| Reddit (r/korea, r/Living_in_Korea 등) | 실제 경험, 영어 | 한국 특화 정보가 얕고 산발적, 검색성 낮음, 오래된 답 |
| 페이스북 그룹 / 카톡방 / 디스코드 | 즉답, 사람 연결 | **축적 0** — 같은 질문 무한 반복, 검색 불가 |
| 블로그/유튜브 | 서사·맥락 | 최신성 불명, 광고성, 파편적 |
| 학교/회사 국제처 | 신뢰 가능 | 소속이 있어야 하고, 범위가 소속 업무로 한정 |
| 네이버 카페 | 소속감, 축적됨, 한국인에게 익숙 | **로그인 담장 -> 검색에 안 걸린다.** 한국어 전용 |
| LinkedIn | 신원 기반 신뢰 | 생활 정보가 아니라 커리어 공간. 실명이 전제 |

**빈 자리**: *한국 특화 + 영어 우선 + 검색 가능하게 축적되는 + 사람이 연결되는* 곳이 없다.
konnect는 이 교집합을 노린다.

## 문제를 푸는 방향 (제품 원칙)

1. **Q&A → 가이드로 승격.** 반복되는 질문은 편집 가능한 문서로 굳힌다(P2, P4 대응).
2. **맥락 태그를 필수화.** 비자 종류·지역·신분을 붙여야 답이 매칭된다(P1 대응).
3. **최신성을 표시한다.** "마지막 확인일"과 "이 절차 아직 유효함" 신호를 콘텐츠에 붙인다(P2 대응).
4. **체크리스트로 순서를 준다.** 도착 전/직후/3개월 등 시점별 할 일을 묶는다(P6 대응).
5. **로컬 만남으로 잇는다.** 정보 다음에 사람 — 밋업·언어교환(P3, P7 대응).
