# 범위와 비범위

## 하는 것

- **Q&A** — 맥락 태그가 붙은 질문/답변
- **가이드** — 반복 질문에서 승격된, 편집 가능한 문서
- **게시판/피드** — 주제별 토론, 후기, 잡담
- **체크리스트** — 시점별(도착 전 / 직후 / 3개월) 할 일 묶음
- **프로필과 평판** — 누가 답했는지, 그 사람이 믿을 만한지
- **밋업/언어교환** — 사람 연결(정보 다음 단계)
- **검색과 태그** — 위 모든 것이 찾아지게 만드는 뼈대

## 하지 않는 것 (비범위)

명시적으로 **하지 않는다**. 나중에 뒤집을 수 있지만, 지금 안 한다는 것을 문서로 못박는다.

| 비범위 | 이유 |
| --- | --- |
| **법률·행정 자문 제공** | 우리는 플랫폼이지 대리인이 아니다. 책임과 정확성 리스크가 크다. → [콘텐츠·리스크 정책](../10-domain/10-visa-immigration/03-content-and-risk-policy.md) |
| **비자 대행 / 서류 제출 대행** | 규제 영역. 초기 조직으로 감당 불가 |
| **부동산 중개·계약 중개** | 라이선스 필요, 분쟁 시 책임 소재 |
| **결제·에스크로** | 초기에 금전이 오가면 신뢰·분쟁·규제 부담이 한꺼번에 온다 |
| **실시간 채팅(1:1 DM)** | 안전·신고·모더레이션 비용이 크다. 공개 글이 먼저 축적되어야 한다 |
| **모바일 네이티브 앱** | 웹(반응형)으로 시작. 앱은 재방문이 증명된 뒤 |
| **자동 번역 전면 도입** | 행정 용어에서 오역이 곧 피해다. 번역은 보조 수단으로만 |
| **한국인 대상 일반 커뮤니티** | 타깃이 흐려지면 어느 쪽에도 안 남는다 |

## 지금 정하지 않는 것 (보류)

- 수익 모델 (광고 / 파트너십 / 프리미엄)
- 모더레이션 조직 형태 (자원봉사 vs 고용)
- 지역 확장 (한국 외 국가)
