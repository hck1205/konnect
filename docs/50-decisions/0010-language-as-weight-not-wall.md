# ADR-0010 · 언어는 벽이 아니라 가중치다 — 그리고 번역으로 잇는다

- **상태**: 수락됨
- **날짜**: 2026-08-27
- **관련**: [ADR-0008](./0008-nationality-as-tag-not-space.md)의 승격 기준을 재사용한다.
  [i18n 전략](../30-architecture/06-i18n-strategy.md)의 열린 질문
  **"작성 언어 태그를 붙여 필터링할 것인가?"** 에 답한다.

## 맥락

"글을 한 곳에 모아두면 **일본어로 쓴 글을 일본어 모르는 사람은 못 본다**"는 지적이 나왔다.
맞다. 그리고 이것은 [ADR-0008](./0008-nationality-as-tag-not-space.md)이
"공간을 나누지 않는다"고 정한 뒤에 남는 **진짜 문제**다.

### 두 주장이 정면으로 충돌한다. 둘 다 맞다

| | 주장 | 근거 |
| --- | --- | --- |
| **나눠야 한다** | 못 읽는 글이 섞이면 피드가 쓸모없다 | 사용자 지적 |
| **나누면 안 된다** | 언어별로 임계질량을 각각 넘어야 한다 | [최대 리스크 = 빈 커뮤니티](../20-product/20-prd/06-risks-and-open-questions.md) |

**초기에는 두 번째가, 성숙기에는 첫 번째가 이긴다.** 시점에 따라 답이 다르다.

> 전체 글 50개(en 20 · vi 15 · ko 10 · ja 5)일 때
> `ja` 사용자에게 하드 필터를 걸면 **5개만 보인다 — 죽은 사이트로 보인다**
>
> 전체 글 5,000개(ja 800)일 때
> 가중치만 주면 못 읽는 글 4,200개가 계속 섞인다 — **노이즈다**

### "한 곳"이 세 가지를 뭉뚱그리고 있다

| 층위 | 나뉘어 있는가 |
| --- | --- |
| **저장·태그 체계** | 한 곳 — 나눌 이유가 없다 |
| **URL·색인** | **이미 나뉘어 있다** (`/ja/...`) — [ADR-0005](./0005-multilingual-from-day-one.md) |
| **피드에 무엇이 보이나** | ← **여기가 질문이다. 아직 안 정했다** |

## 결정

**언어를 하드 경계로 쓰지 않는다. 정렬 가중치로 시작해, 임계질량을 넘은 언어만 필터로 승격한다.
그리고 못 읽는 글은 요청 기반 번역으로 잇는다.**

### 1. 모든 글에 작성 언어 태그를 붙인다 (`lang:`)

- **자동 감지 + 작성 시 사용자 확인.** 자동만 쓰면 짧은 글·혼용 글에서 틀린다
- 한국어 원문 병기(`외국인등록증`)가 흔하므로 **혼용을 오탐하지 않게** 주 언어를 고른다
- 태그이지 카테고리가 아니다 — [ADR-0008](./0008-nationality-as-tag-not-space.md)과 같은 원칙

### 2. 피드는 가중치로 시작한다

| 대상 | 기본 동작 |
| --- | --- |
| 로그인 사용자 | **프로필의 "사용 언어"** 글을 위로. 나머지는 아래에 그대로 보인다 |
| 비로그인 | **UI 로케일**이 유일한 힌트다. 그 언어를 위로 |
| 항상 | 각 글에 **언어 라벨**이 붙어 사용자가 스스로 판단한다 |
| 항상 | **"모든 언어 보기" 토글**이 있다 |
| **검색** | **언어를 가리지 않는다.** 검색은 의도가 이미 명확하다 |

**읽을 수 있는 언어는 하나가 아니다.** 프로필의 사용 언어가 이미 복수를 담는다 —
`ja` + `en` 을 읽는 사람은 둘 다 위로 온다.

### 3. 임계질량을 넘으면 하드 필터로 승격한다

[ADR-0008 의 승격 기준을 그대로 쓴다](./0008-nationality-as-tag-not-space.md):

> 해당 언어의 **주간 신규 글이 4주 연속 10건 이상**이고
> **답변률이 전체 평균 이상**이면, 그 언어를 기본 필터로 승격한다.

**규칙 하나가 태그→공간 승격과 언어 필터 강도를 둘 다 다룬다.**
"그 언어만 봐도 피드가 살아 있을 때" 비로소 벽을 세우는 것이다.

### 4. 못 읽는 글은 번역으로 잇는다 — 원문을 대체하지 않고

[ADR-0003](./0003-english-first-multilingual.md)이 배제한 것은 **전면 자동 번역**이다.
**사용자가 요청하는 문단 단위 번역**은 배제 대상이 아니고, 이미
[C5 요구사항](../20-product/20-prd/04-requirements.md)에 있다.

| 규칙 | 이유 |
| --- | --- |
| **원문을 대체하지 않는다.** 원문 옆에 붙인다 | 원문이 사라지면 검증할 방법이 없어진다 |
| **"기계 번역" 표시 필수** — 사용자의 언어로 | 표시 없는 번역은 사실 주장이 된다 |
| **R1(비자·법률) 글은 경고를 강화** | [오역이 곧 피해](../10-domain/10-visa-immigration/03-content-and-risk-policy.md) |
| **요청 시에만.** 자동으로 돌리지 않는다 | [비용이 제약이다](../20-product/20-prd/07-monetization.md#비용이-이제-제약이다) |
| **(글, 대상 언어) 쌍으로 캐시** | 같은 번역을 두 번 사지 않는다. 인기 글일수록 효율이 좋아진다 |
| **번역본을 색인하지 않는다** | 별도 URL 로 색인하면 중복·저품질 콘텐츠가 된다. 원문만 색인한다 |

**이것이 "나누지 않으면서 읽히게 하는" 유일한 방법이다.** 벽을 세우는 대신 다리를 놓는다.

### 5. 언어를 국기로 표시하지 않는다

"사용 언어를 flag 로 표기하자"는 제안이 있었으나 **채택하지 않는다.**

**언어와 국가는 일대일이 아니다.**

| 언어 | 어느 국기를? |
| --- | --- |
| 영어 | 미국·영국·인도·필리핀·나이지리아… |
| 중국어 | 중국·대만·싱가포르 — **정치적으로 폭발적이다** |
| 러시아어 | 러시아? **우즈벡·카자흐 사용자에게 러시아 국기를 붙이는 것은 매우 민감하다** |
| 스페인어 | 스페인·멕시코·아르헨티나… |

그리고 [ADR-0009](./0009-nationality-display-policy.md)가 국기를 배제한 이유
(정치적이고, 시각적으로 너무 강해 편견을 앞당긴다)가 그대로 적용된다.
**언어에 국기를 붙이면 국적 표시가 우회로로 부활한다** — 사용자는
"일본어 국기"를 보고 "일본인"으로 읽는다.

**대신 그 언어 이름을 그 언어로 적는다**(endonym): `English` · `한국어` · `中文` · `Tiếng Việt`.
**코드가 이미 그렇게 되어 있다** (`FE/src/lib/i18n/locales.ts` 의 `LOCALE_LABELS`,
그리고 `LocaleSwitcher` 는 국기가 아니라 `Languages` 아이콘을 쓴다).
국기로 바꾸는 것은 후퇴다.

## 결과

**좋은 점**
- 초기에 피드가 텅 비지 않는다 — 최대 리스크를 언어 수만큼 곱하지 않는다
- **성숙기에는 자동으로 깔끔해진다.** 수동 판단이 필요 없다
- 커뮤니티가 언어로 갈라지지 않는다 — 번역이 다리 역할을 한다
- 승격 규칙이 **하나**다. 태그·언어에 같은 기준을 쓴다

**비용**
- **초기 피드에 못 읽는 글이 섞인다.** 이것이 이 결정의 실제 대가다 —
  "죽은 사이트로 보이는 것보다 낫다"는 판단이지, 공짜가 아니다
- 번역 API 비용이 든다. 캐시로 줄이지만 0 은 아니다
- 가중치 정렬은 하드 필터보다 **구현이 복잡하다**
- `lang:` 자동 감지가 틀리면 정렬이 어긋난다 → 사용자 확인이 전제다

## 대안

| 대안 | 왜 안 골랐나 |
| --- | --- |
| **처음부터 언어별 하드 필터** | 초기에 각 언어 피드가 텅 빈다. 빈 커뮤니티가 최대 리스크다 |
| 언어별 사이트 분리 | ADR-0008 이 국적 카테고리를 거부한 논리와 같다. 모수가 쪼개진다 |
| 전면 자동 번역 | [ADR-0003](./0003-english-first-multilingual.md)이 배제했다. 행정 용어 오역은 실제 피해다 |
| 아무것도 안 한다 (지금) | 지적이 옳다. 못 읽는 글이 섞인 채로 두면 피드가 쓸모없어진다 |
| 언어를 국기로 표시 | 언어 ≠ 국가. 정치적이고, 국적 표시를 우회로로 부활시킨다 |

## 열린 질문

- 승격 기준의 **"주 10건"이 언어에도 맞는 숫자인가?** ADR-0008 에서 가져온 값이고
  **근거 없는 초기값**이다
- 가중치를 얼마나 줄 것인가? 내 언어 글이 **항상** 위면 오래된 글이 계속 상단에 남는다
  → 신선도와 어떻게 섞나
- `lang:` 자동 감지를 무엇으로 하나? 한국어 원문 병기가 흔해 오탐 위험이 있다
- 번역 요청이 **남용**되면 비용이 튄다. 사용자당 한도가 필요한가?
- 번역된 글을 사용자가 **다시 인용**하면 원문 추적이 끊긴다. 어떻게 붙들 것인가?
