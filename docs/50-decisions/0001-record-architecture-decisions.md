# ADR-0001 · ADR을 기록한다

- **상태**: 수락됨
- **날짜**: 2026-08-24

## 맥락

konnect는 초기 단계라 결정이 빠르게 쌓인다. 시간이 지나면 코드에는 **결과만** 남고
**이유는 사라진다.** 그러면 다음 두 가지가 일어난다:

1. 이미 검토하고 버린 선택지를 다시 검토한다
2. 이유를 모르는 채로 바꿨다가 원래 있던 제약을 밟는다

특히 이 서비스에는 **겉보기에 이상해 보이는 결정**이 여럿 있다
(국내 소셜 로그인을 후순위로 두는 것, 결제·DM을 안 하는 것, 문서 언어와 UI 언어가 다른 것).
이유가 없으면 나중에 누군가 "이건 실수겠지" 하고 뒤집는다.

## 결정

**되돌리기 어려운 결정을 ADR로 남긴다.** `docs/50-decisions/`에 연번으로 쌓는다.

- 형식은 짧게: 맥락 / 결정 / 결과 / 대안
- 수락된 ADR은 **수정하지 않는다**. 바뀌면 새 ADR이 이전 것을 대체한다
- 코드 리뷰에서 "이건 ADR감이다"라고 지목할 수 있게 한다

## 결과

**좋은 점**
- 결정의 이유가 코드 밖에 남는다
- 새로 합류한 사람이 "왜 이렇게 되어 있나"를 스스로 읽을 수 있다

**비용**
- 문서를 쓰는 시간. → **되돌리기 어려운 것만** 쓰는 것으로 비용을 통제한다

## 대안

- **아무것도 안 함** — 지금까지의 기본값. 결정의 이유가 사라진다
- **커밋 메시지에 의존** — 검색이 어렵고, 여러 커밋에 걸친 결정을 담지 못한다
- **위키** — 저장소 밖에 있으면 코드와 함께 갱신되지 않는다
