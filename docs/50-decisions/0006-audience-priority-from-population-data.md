# ADR-0006 · 타깃 우선순위를 인구 데이터로 재조정한다

- **상태**: 수락됨
- **날짜**: 2026-08-27
- **관련**: [00-overview/03-target-users](../00-overview/03-target-users.md) 의 **"초기 집중"** 과
  페르소나를 대체한다. 세그먼트를 나누는 방식(체류 목적별) 자체는 유효하다.

## 맥락

초기 타깃을 **"S1 유학생 + S2 직장인(E-7 개발자)"** 으로 잡았다.
그때는 근거가 **추측**이었다 — "문제 밀도가 높고 검색 의도가 명확할 것 같다".

[체류외국인 통계](../20-product/20-prd/01-market-data.md)를 실제로 확인하니
가정 두 개가 데이터와 맞지 않았다.

**1. 영어권 전문직은 모수의 주변부다.**
체류외국인 2,783,247명(2025-12) 중 미국 국적은 180,230명(6.5%)이고
그중에서도 E-7 전문인력은 일부다. 페르소나 3인 중 2인이 이 좁은 층을 향해 있었다.

**2. 실제로 성장하는 축은 베트남 유학생이다.**

| 축 | 증감 |
| --- | --- |
| 유학 체류자격 | 308,838, **+17.1%** (유일한 두 자릿수) |
| 베트남 국적 | 337,183, **+10.2%** (증가폭 1위) |
| **유학생 중 베트남** | 115,131 → **중국을 제치고 1위 (36.6%)** |
| 유학생 중 중국 | 86,179 → 78,529 (**감소**) |

그리고 인구 1위인 중국 국적 980,670명은 **한국어 대안을 이미 갖고 있다**
(F-4 재외동포 556,208명이 대리 지표). 모수가 크다고 우리가 줄 것이 있는 것은 아니다.

**3. 지역 전제도 틀렸다.** 수도권 밖이 43.2%이고 밀도 최상위는 서울이 아니라
안산(16.1%)·영암(21.1%)·음성(19.9%) 같은 산업단지 배후 도시다.

## 결정

**타깃 우선순위를 "모수 × 도달가능성 × 문제밀도 × 잔존기간" 네 축으로 다시 계산하고,
그 결과를 따른다.**

- **1차 타깃은 베트남 국적 유학생과 그 졸업 후 전환자**다.
  성장하는 모든 축의 교집합이며, 네 축이 전부 좋은 유일한 세그먼트다
- **유학생과 전환자를 하나의 회로로 본다.** 유학생의 62.8%가 졸업 후 체류를 계획한다 —
  졸업은 이탈 지점이 아니라 **답변자로 전환되는 지점**이다
- **인구 1위(중국·동포)를 P3 으로 내린다.** 문제밀도가 낮다
- **E-9 노동자(문제밀도 1위)를 타깃이라고 말하지 않는다.** 지금 구조로는 못 닿는다.
  모바일 + 자국어 + 익명 보장이 갖춰지기 전까지 **열린 질문으로 남긴다**
- **여행자(S5)를 명시적으로 제외한다.** 잔존기간이 짧다
- **지역 축의 기본값에서 서울을 뺀다.** 시·군 단위가 1급 시민이다.
  단 유학생에게는 지역보다 **학교**가 더 강한 축이며, 둘은 별개 필터다
- **번역·콘텐츠 투자는 `vi` 가 `zh` 보다 먼저다.** `en` 은 기준 언어로 유지하되
  그것은 **폴백과 공통 언어**의 역할이지 1순위 투자 대상이라는 뜻이 아니다

상세는 [20-prd/](../20-product/20-prd/) 가 갖는다.

## 결과

**좋은 점**
- 타깃이 **검증 가능한 숫자**에 묶였다. 다음에 바꿀 때도 같은 방식으로 계산한다
- 자원 배분의 기준이 생겼다 — `vi` 검수가 `ja` 추가보다 먼저인 이유를 설명할 수 있다
- "인구 1위를 타깃 1위로" 라는 흔한 실수를 문서로 막았다

**비용**
- **문제가 가장 심각한 집단(E-9)을 당장 돕지 못한다.** 이것을 완화라고 부르지 않는다 —
  도달 수단이 없다는 것을 인정하는 것이고, 편한 결정이 아니다
- 페르소나·여정 문서를 다시 써야 한다
- 판단이 **증감 방향**에 걸려 있어 매년 재계산이 필요하다.
  베트남 증가·중국 감소가 꺾이면 결론이 바뀐다

## 대안

| 대안 | 왜 안 골랐나 |
| --- | --- |
| **인구 1위(중국) 우선** | 한국어 대안을 이미 갖고 있어 문제밀도가 낮다. 유학생 수는 오히려 줄고 있다 |
| **문제가 가장 심각한 E-9 우선** | 옳은 방향이지만 웹으로 닿지 않는다. 닿지 못하는 타깃은 타깃이 아니다 — 먼저 도달 수단을 만들어야 한다 |
| 기존 영어권 전문직 유지 | 모수 6.5%의 일부. 그리고 영어권 커뮤니티는 이미 존재한다 |
| 세그먼트를 좁히지 않고 전부 대상 | 언어별로 임계질량을 따로 넘어야 하는데, 넓히면 **어느 언어도 못 넘는다** |

## 열린 질문

- E-9 세그먼트 도달 수단 — 익명 보장이 정보 신뢰(R2)와 충돌한다. 어떻게 양립시키나?
- 한국인 사용자를 정식 유형으로 받는가? (이전 문서의 열린 질문이 그대로 유효하다)
- `vi` 콘텐츠가 임계점을 넘었다는 것을 **무엇으로 판정하는가?**
