# ADR-0004 · 1:1 쪽지를 도입하되 안전 장치를 전제로 한다

- **상태**: 수락됨
- **날짜**: 2026-08-24
- **관련**: [비범위 문서](../00-overview/04-scope-and-non-goals.md)의 "실시간 채팅(1:1 DM)" 항목을 **뒤집는다**

## 맥락

초기 비범위 문서는 1:1 DM 을 명시적으로 제외했다. 이유는 **안전·신고·모더레이션
비용이 크고, 공개 글이 먼저 축적되어야 한다**는 것이었다.

그 판단이 틀렸다고 보지 않는다. 다만 제품 요구가 바뀌었다 — 쪽지가 있어야
성립하는 흐름이 있다:

- 답변자에게 **후속 질문**을 하려는데 공개 댓글에 개인 상황(회사명, 학교, 체류자격
  세부)을 쓸 수 없다. 그건 공개하면 안 되는 정보다.
- 밋업 참가자끼리 **약속을 조율**해야 한다.
- 언어교환 상대를 찾은 뒤 이어질 통로가 없다.

동시에 원래의 위험은 그대로다. 오히려 더 크다: 타깃 사용자는 언어가 불편하고,
현지 지원망이 없고, 체류자격이 걸려 있어 신고를 주저한다. 호의를 가장한 접근에
노출되며, **피해 가능성이 높고 회복이 어렵다**
([안전과 신뢰](../10-domain/60-social-community/02-safety-and-trust.md)).

## 결정

**1:1 쪽지를 도입한다. 단, 아래 장치가 전부 갖춰진 뒤에만 연다.**

이건 권고가 아니라 **출시 조건**이다. 하나라도 빠지면 기능을 켜지 않는다.

1. **안전 고지 상시 노출** — 대화 상단에, 닫을 수 없게.
   금전·여권·외국인등록증 요구를 거절하라는 내용. 사기가 가장 자주 시작되는 경로다.
2. **차단과 신고를 한 번의 조작으로** — 대화 헤더 안에. 메뉴 깊숙이 두지 않는다.
3. **민감정보 형태 경고** — 여권번호·13자리 번호 형태를 보내기 전에 경고한다.
   **막지는 않는다**(오탐이 있을 수 있고, 오탐이 잦으면 경고를 무시하게 된다).
4. **수신 거부 설정** — 쪽지를 아예 받지 않을 수 있어야 한다.
5. **신고 긴급 트랙** — 쪽지 신고는 사기·개인정보 트랙으로 들어간다.
6. **금전 거래 금지 정책** — 위반 시 제재. 서비스 안에서 돈이 오가지 않게 한다.

### 아직 하지 않는 것

- **실시간 채팅이 아니다.** 읽음 표시와 폴링까지다. WebSocket 상시 연결은 없다 —
  실시간성이 대화의 성격을 바꾼다(즉답 압박이 생기고, 그만큼 사기 수법이 통한다).
- **첨부 파일 없음.** 서류 사진을 주고받는 순간 이 기능의 위험이 몇 배가 된다.
- **모르는 사람에게 먼저 보내기**는 계정 나이·활동 이력 조건을 붙일지 검토 중이다(열린 질문).

## 결과

**좋은 점**
- 공개할 수 없는 개인 상황을 다룰 통로가 생긴다
- 밋업·언어교환이 실제로 성사될 수 있다

**비용**
- 모더레이션 부담이 실질적으로 늘어난다. 공개 글과 달리 **커뮤니티가 자정할 수 없다** —
  아무도 볼 수 없는 곳에서 일어나기 때문이다
- 신고 처리 인력·시간이 필요하다. 이 비용을 감당할 수 없으면 기능을 여는 것이 무책임하다
- 사기 피해가 발생하면 서비스의 신뢰가 무너진다

**되돌리는 방법**
기능을 끄는 것은 가능하다(기존 대화는 읽기 전용으로). 그래서 이 결정은
데이터 모델보다 되돌리기 쉽다 — 다만 **이미 발생한 피해는 되돌릴 수 없다.**

## 대안

| 대안 | 왜 안 골랐나 |
| --- | --- |
| **그대로 비범위 유지** | 위 세 가지 흐름이 막힌다. 특히 "공개 댓글에 쓸 수 없는 개인 상황"은 실제 요구다 |
| 공개 프로필에 외부 연락처 표기 | 서비스 밖으로 나가면 신고·차단이 아예 불가능하다. **더 위험하다** |
| 밋업 참가자 사이에서만 허용 | 후속 질문 흐름을 못 푼다. 조건이 복잡해 사용자가 이해하기 어렵다 |
| 실시간 채팅으로 구현 | 즉답 압박이 사기 수법의 효과를 키운다. 비동기 쪽지가 이 서비스에 더 맞다 |

## 열린 질문

- 모르는 사람에게 먼저 보내기에 조건(계정 나이·활동 이력)을 붙일 것인가?
- 신고 처리 인력을 어떻게 확보할 것인가? **이게 해결되지 않으면 기능을 열지 않는다.**
- 대화 보존 기간 — 무기한 보관하면 유출 시 피해가 커진다
