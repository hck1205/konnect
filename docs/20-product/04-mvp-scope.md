# MVP 범위

## MVP의 목표

> **"같은 질문에 두 번째 사람이 답을 검색으로 찾을 수 있다"**를 증명한다.

이게 되면 서비스가 성립하고, 안 되면 다른 걸 아무리 붙여도 소용없다.
그래서 MVP는 [J1(검색 유입) + J2(답변자)](./03-user-journeys.md) 두 여정만 만든다.

## 포함 (P0)

| # | 항목 | 완료 기준 |
| --- | --- | --- |
| 1 | 소셜 로그인 | 구글 로그인으로 계정 생성, JWT 발급 — ⏳ **임시 로그인만 구현**(OAuth 미완) |
| 2 | 질문 작성/조회 | 비로그인 읽기 가능, 로그인 시 작성 — ✅ BE 완료 |
| 3 | 답변 작성 + 채택 | 질문자가 답변 하나를 채택 — ✅ BE 완료 |
| 4 | 태그 | 고정 어휘(`visa` `topic` `region` `nationality` `lang`) + 자유 태그 — ✅ BE 완료 (값 추가 필요) |
| 5 | 목록 + 태그 필터 | 주제·태그로 좁히기 — ✅ BE 완료(키셋 커서) |
| 6 | 검색 | 제목·본문 텍스트 검색 — ⏳ 인메모리만(Postgres 전문검색 미완) |
| 7 | 프로필 | 닉네임, 아바타, 내가 쓴 글 |
| 8 | 신고 | 모든 글/답변에 신고 버튼, 관리자 목록 |
| 9 | SEO | SSR · 메타 · **`sitemap.xml`** · **`hreflang`** · `canonical` · **`QAPage`** — [셋은 선택이 아니다](../30-architecture/07-routes-and-indexing.md) |
| 10 | **다국어 UI** | en/ko/zh/vi. 로케일이 URL 세그먼트, `Accept-Language` 협상 |
| 11 | 댓글 · 답글(한 단계) | 답글의 답글은 한 단계로 접는다 |
| 12 | 공감 표시 | 고정 어휘 이모지 5종, 한 사람이 하나 |

## 제외 (MVP 아님)

가이드 승격 · 체크리스트 · 알림 · 게시판 · 평판 · 밋업 · **1:1 쪽지** · 북마크 · 이미지 업로드

> **쪽지를 MVP 에서 뺀 이유**: 기능이 아니라 **운영 준비**가 전제다 —
> 신고 처리 인력이 확보되기 전에는 열지 않는다
> ([ADR-0004](../50-decisions/0004-direct-messages-with-safety-gates.md)).
> 컴포넌트는 만들어 두었지만 화면에 붙이지 않는다.

> **가이드를 뺀 이유**: 승격할 Q&A가 없는 상태에서 가이드 기능은 빈 껍데기다.
> Q&A가 먼저 쌓여야 한다.

## 릴리스 단계

> **시간 축은 `Phase` 하나다.** 예전에는 여기서 `M1~M4` 를 따로 썼는데,
> [콘텐츠 축](./20-prd/09-content-pillars.md)·[라우트](../30-architecture/07-routes-and-indexing.md)가
> 쓰는 `Phase` 와 뜻이 겹치면서 **같은 시점을 두 이름으로 부르게 됐다.** `Phase` 로 합친다.

| Phase | 범위 | 나가는 질문 |
| --- | --- | --- |
| **1** | 위 P0 전부 | 검색으로 들어온 사람이 답을 찾는가? |
| **2a** | 알림 + 게시판 + 가이드 승격 | 답변자가 다시 오는가? |
| **2b** | 체크리스트 + 평판 | 정착 문제가 실제로 풀리는가? |
| **3** | 밋업 + 1:1 쪽지 · 리스팅 | 사람이 연결되는가? **신고 처리 체계와 법률 검토가 먼저다** |

각 단계는 앞 단계의 질문에 **답이 나온 뒤**에 시작한다. 답이 "아니오"면 다음 단계가 아니라 수정이다.

### 다른 축과의 관계

세 축이 각각 다른 것을 센다. 헷갈리지 않게 여기 모아 둔다.

| 축 | 무엇을 세는가 | 누가 정하는가 |
| --- | --- | --- |
| **Phase 1·2·3** | **언제 만드는가** — 이 표 · [콘텐츠](./20-prd/09-content-pillars.md) · [라우트](../30-architecture/07-routes-and-indexing.md) | 우리 |
| `P0`·`P1`·`P2` | **무엇이 먼저인가** (우선순위, 시점 아님) → [핵심 기능](./02-core-features.md) | 우리 |
| `Stage 0~4` | **언제 팔리는가** → [수익](./20-prd/07-monetization.md) | **트래픽** — 우리가 정하지 못한다 |

## 콘텐츠 시딩 (기능보다 중요할 수 있음)

빈 Q&A 사이트는 아무도 안 쓴다. 출시 시점에 **최소 30~50개의 실제 질문/답변**이 필요하다.

- **얕은 글 100개보다 끝까지 답하는 글 20개** — 방법과 조건은 [08-seo](./20-prd/08-seo-strategy.md#콜드스타트--닭과-달걀)
- 이건 **개발 작업이 아니라 콘텐츠 작업**이다. 별도 일정으로 잡아야 한다.
