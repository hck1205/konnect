# 06 · 리스크와 열린 질문

> 타깃이 **정주 의도**로 바뀌면서 리스크 지형이 달라졌다
> ([ADR-0007](../../50-decisions/0007-settlement-intent-as-primary-axis.md)).
> **유입 속도**와 **민감도**가 새 리스크로 올라온다.

## 리스크

| # | 리스크 | 왜 위험한가 | 완화 |
| --- | --- | --- | --- |
| R1 | **유입 주기가 없다** | 유학생은 입학 시즌마다 코호트가 갱신되지만 **정주자는 그런 주기가 없다.** 초기 성장이 완만하다 | 검색 유입에 전적으로 의존한다 → 영주·귀화 절차 콘텐츠를 **먼저 채우고** 연다 |
| R2 | **빈 커뮤니티** | 질문에 답이 안 달리면 한 번 오고 안 온다 | 비치헤드를 국적 무관한 **영주·귀화 관문**으로 잡아 언어별 임계질량을 각각 넘지 않게 했다. 초기엔 운영진이 직접 답한다 |
| R3 | **틀린 영주·귀화 정보** | 신청 실패는 **몇 년을 잃는 것**이다. 유학 정보보다 실패 비용이 크다 | 신선도 표시 · 공식 출처 링크 · **자문이 아니라는 고지** · 오래된 답변 자동 표시 |
| R4 | **제도 변경 속도** | 영주·귀화 요건은 자주 바뀌는데 **답변은 몇 년씩 남는다.** 낡은 정답이 오답이 된다 | 갱신 이력 · 관심사별 갱신 책임자(미정) |
| R5 | **C(결혼이민) 확장 시 안전 요구 급등** | 배우자 갈등·가정폭력·이혼 시 체류자격 상실이 실제 주제다. **체류자격이 배우자에게 묶인 사용자**에게 신원 노출은 곧 위험이고, **배우자가 이 사이트를 볼 수 있다** | [ADR-0004](../../50-decisions/0004-direct-messages-with-safety-gates.md) 안전장치 7종 **전부**가 C 진입의 전제. 하나라도 빠지면 열지 않는다 |
| R6 | **다문화가족지원센터라는 기존 강자** | 전국 200여 개, 정부 예산, 통역·상담 무료. C 로 바로 들어가면 진다 | C 를 비치헤드로 삼지 않는다. 우리가 나은 지점(**24시간·익명·또래 경험·검색 가능**)이 통하는 A 부터 |
| R7 | **OAuth 미구현** | **아무도 글을 쓸 수 없다.** 현재 유일한 하드 블로커 | [M6](./04-requirements.md) |
| R8 | **동일인 식별 부재** | 로그인할 때마다 새 계정이 된다 → **평판이 쌓이지 않는다.** 정주 타깃에서는 평판이 핵심 자산이라 더 치명적이다 | OAuth 도입 시 `AuthIdentity(provider, providerId)` 로 해결 |
| R9 | **번역 품질** | `zh`·`vi` 원어민 검수 전. 행정 용어 오역은 R3 과 같은 피해 | **출시 차단 조건.** 검수 전 공개 금지 |
| R10 | **모바일 미대응** | 수도권 밖 43% · 근로 세그먼트는 스마트폰 단독 | [S6](./04-requirements.md). DS 는 준비됐으나 화면이 아직 없다 |

### R5 를 다시 강조한다

C(결혼이민)는 모수가 크고 정주 의도가 확정적이라 **당겨 오고 싶어지는 세그먼트**다.
그 유혹을 문서로 막아 둔다.

- 결혼이민자 다수가 여성이고, **체류자격이 배우자에게 묶여 있다**
- 이혼·별거 시 체류자격을 잃을 수 있어 **질문 자체가 위험을 만든다**
- 공개 커뮤니티에서는 **배우자·시댁이 글을 볼 수 있다**
- 귀화자의 51.0%가 혼인귀화라는 사실은, 이 집단이 **귀화 관문에 몰려 있다**는 뜻이기도 하다
  — 즉 A 로 들어와도 C 의 문제를 들고 온다

**A 로 시작해도 C 의 사용자가 섞여 들어온다.** 안전장치를 "C 진입 시"가 아니라
**처음부터** 갖춰야 하는 이유다.

## 열린 질문

### 유입

- **초기 유입을 무엇으로 만드나?** 정주자에게는 입학 시즌 같은 자연 주기가 없다.
  검색 외의 경로가 있는가?
- 영주·귀화 콘텐츠를 **누가 먼저 채우는가?** R1·R2 의 실질적 답이 여기 걸려 있다
- 행정사·이민 전문가를 **공식 답변자로** 받을 것인가?
  정확도는 오르지만 **광고판이 될 위험**이 있다

### 세그먼트

- C(결혼이민) 진입 시점을 **안전장치 7종 완비 이후로 못 박을 것인가?**
- F(E-9 노동자)에 어떻게 닿는가? 익명 보장이 정보 신뢰(R3)와 충돌한다
- 한국인 사용자를 정식 유형으로 받는가? **정주 타깃에서는 한국인 배우자·동료가
  실제로 답을 갖고 있어** 유학 타깃 때보다 가치가 크다

### 제품

- 영주권 **점수 계산기**를 만들 것인가? 유입 가치가 크지만
  **틀리면 R3 그 자체**이고, 제도 변경 시 즉시 오답이 된다
- 관심사별 **갱신 책임자**를 둘 것인가? (R4)
- 정보와 자문의 선을 UI 에서 **어떻게 보이게** 할 것인가?

### 데이터

- **F-5 전체·F-2 거주 인원을 확인하지 못했다.** 비치헤드 규모 추정의 정확도가 여기 걸려 있다
- 이 PRD 의 판단은 **증감 방향**에 걸려 있다. 귀화·영주 증가세가 꺾이면 재계산한다
- 최근 조사(2024·2025)의 어려움 문항이 바뀌어 **2022년분과 시계열이 끊겼다**
- 누적 결혼이민 국적 구성은 **2021년 자료**다. 최신으로 갱신해야 한다
