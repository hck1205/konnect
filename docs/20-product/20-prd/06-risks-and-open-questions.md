# 06 · 리스크와 열린 질문

## 리스크

| # | 리스크 | 왜 위험한가 | 완화 |
| --- | --- | --- | --- |
| R1 | **빈 커뮤니티** | 질문에 답이 안 달리면 한 번 오고 안 온다. 언어별로 나누면 **각 언어가 따로 임계질량을 넘어야 한다** — 4개 언어면 4배 어렵다 | `vi` 하나에 집중해 먼저 임계점을 넘긴다. 초기엔 운영진이 직접 답한다 |
| R2 | **틀린 비자 정보** | 체류 자격이 끊기는 실제 피해. 커뮤니티 답변은 **검증되지 않는다** | 신선도 표시(M9) · 공식 출처 링크 · 자문이 아니라는 고지 · 오래된 답변 자동 표시 |
| R3 | **번역 품질** | `zh`·`vi` 원어민 검수 전. 행정 용어 오역은 R2 와 같은 피해 | **출시 차단 조건.** 검수 전 공개 금지 |
| R4 | **DM 악용** | 신원·언어 취약자 대상 스팸·사기·괴롭힘. 유학생은 표적이 되기 쉽다 | [ADR-0004](../../50-decisions/0004-direct-messages-with-safety-gates.md) 안전장치 7종 **전부** 전제. 하나라도 빠지면 열지 않는다 |
| R5 | **신원 노출 역풍** | 고용주·학교 관련 질문에서 작성자가 특정되면 **실제 보복**이 가능하다 | 실명 인증 안 함. 프로필 최소화. 태그 조합만으로 특정되지 않는지 점검 |
| R6 | **OAuth 미구현** | **아무도 글을 쓸 수 없다.** 현재 유일한 하드 블로커 | M6. 그 전까지는 회로 검증 불가 |
| R7 | **동일인 식별 부재** | 지금은 로그인할 때마다 새 계정이 된다 → 평판이 쌓이지 않는다 | OAuth 도입 시 `AuthIdentity(provider, providerId)` 로 해결 |
| R8 | **모바일 미대응** | 근로 세그먼트·수도권 밖은 스마트폰 단독 | S6. DS 는 준비됐으나 화면이 아직 없다 |

## 열린 질문

### 세그먼트

- **D(E-9 노동자)에 어떻게 닿을 것인가?** 문제밀도 1위인데 도달 수단이 없다.
  모바일 + 자국어 + **익명 보장** 셋이 전제인데, 익명은 R2(정보 신뢰)와 충돌한다.
  → 답이 나오기 전까지 **타깃이라고 말하지 않는다**
- 한국인 사용자를 정식 유형으로 받는가? 받으면 권한·표시를 어떻게 나누는가?
  (도우미·언어교환 상대로서 가치가 크지만, 다수가 되면 성격이 바뀐다)
- E(결혼이민)는 오프라인 지원(다문화가족지원센터)이 이미 강하다.
  온라인에서 우리가 나을 지점이 무엇인가?

### 제품

- 초기 콘텐츠를 **누가 만드는가?** R1 의 실질적 답이 여기 걸려 있다
- 학교별 하위 커뮤니티의 **임계점은 몇 명인가?** 넘기 전에 만들면 빈 방이 늘어난다
- 비자 정보의 **갱신 책임자**를 둘 것인가? 제도는 바뀌는데 답변은 남는다

### 데이터

- 이 PRD 의 판단은 **증감 방향**에 걸려 있다.
  베트남 증가·중국 감소가 꺾이면 [02](./02-segments-and-priority.md) 를 다시 계산해야 한다
- 최근 조사(2024·2025)의 어려움 문항이 바뀌어 **2022년분과 시계열이 끊겼다.**
  "언어가 1순위"라는 방향은 유지되지만 **수치 추세는 못 본다**
- 태국 감소(−10%)가 일시적인지 구조적인지 아직 모른다. 1년 더 봐야 한다
