# 09 · 유입 기둥 — 무엇으로 시작하는가

후보로 나온 것: **거주 · 직장(파트타임·정규직·프리랜서) · 물물교환 · 비자**

이 문서는 그 넷을 **하나의 축으로 다시 묶고, 순서를 매긴다.**

## 넷이 아니라 하나다 — 비자는 카테고리가 아니라 축이다

비자를 다섯 번째 주제로 나란히 두면 안 된다. **나머지 셋을 전부 관통하고 있다.**

| 표면 주제 | 실제로 걸리는 것 |
| --- | --- |
| 집을 계약한다 | 외국인등록증이 있어야 한다. **체류기간과 계약기간이 어긋나면 계약이 성립하지 않는다** |
| 이사한다 | **체류지 변경 신고** 의무가 따라온다 |
| 아르바이트를 한다 | **시간제취업 허가**가 필요하다. D-2 는 TOPIK 등급 요건까지 있다 |
| 정규직으로 옮긴다 | 체류자격이 그 업무를 허용해야 한다. 스폰서가 바뀐다 |
| 프리랜서로 일한다 | **대부분 자격 외 활동이다.** 허가 없이 하면 불법이다 |
| 물건을 판다 | 반복·영리 규모가 되면 사업 활동이 된다 |

**이것이 당근·알바몬·직방에 대한 유일한 우위다 — 그들은 비자를 모른다.**
"이 집 좋아요"는 그들이 더 잘하지만, **"이 계약이 내 체류자격으로 가능한가"는 그들이 답할 수 없다.**

그래서 콘텐츠의 형태는 이래야 한다:

> ❌ "외국인 전세 계약하는 법"
> ✅ **"D-2 체류기간이 8개월 남았는데 2년 전세 계약이 되나?"**

두 번째만 우리가 이긴다. 그리고 [고의도 트래픽](./07-monetization.md)도 두 번째다.

## 넷은 성격이 다르다 — 정보와 리스팅을 섞지 않는다

| 주제 | 유형 | 콜드스타트 | SEO | 규제 |
| --- | --- | --- | --- | --- |
| **비자** | 순수 정보 | **쉽다 — 혼자서도 쓴다** | **최고** | 자문 경계만 |
| **거주** | 정보 + 매물 | 정보는 쉽다 | 좋다 | 매물은 공인중개사법 |
| **직장** | 정보 + 공고 | 정보는 쉽다 | 좋다 | **공고는 무겁다 — 아래 참고** |
| **물물교환** | **순수 거래** | **가장 어렵다 (양면 시장)** | **거의 없다** | 분쟁·사기 |

**리스팅은 SEO 자산이 되지 않는다.** 매물·공고·중고 물건은 **팔리면 사라진다.**
색인돼 봐야 죽은 페이지가 되고, 죽은 페이지가 쌓이면 사이트 품질 평가가 깎인다.

[유일한 유입 채널이 SEO](./08-seo-strategy.md)인 상황에서 이것은 결정적이다 —
**리스팅 먼저 만들면 유입이 안 생긴다.**

## ⚠️ "직장"의 규제가 생각보다 무겁다

이건 확인하고 나서 알았다. 직업안정법(유료직업소개)만 보고 있었는데,
**출입국관리법이 더 무겁다.**

| | |
| --- | --- |
| 자격 외 활동을 한 외국인 | **3년 이하 징역 또는 3천만원 이하 벌금** |
| **고용하거나 고용을 알선한 자** | **동일하게 3년 이하 징역 또는 3천만원 이하 벌금** |

**"알선한 자"에 플랫폼이 들어갈 수 있다.** 자격이 없는 사람에게 일자리를 연결한
결과가 되면, 우리가 중개 수수료를 받지 않아도 문제가 될 수 있다.

그리고 이 오디언스에는 **자격 외 활동이 실제로 흔하다** — 프리랜서, 허가 없는
아르바이트, E-9 의 다른 일. 즉 **구인 공고 게시판은 위험이 실재한다.**

**결정: 구인·구직 리스팅은 Phase 2 로 미루고, 법률 검토를 선행 조건으로 건다.**
정보(Q&A)는 안전하다 — "이 자격으로 이 일이 되나"를 알려 주는 것은
알선이 아니라 **오히려 위반을 막는 쪽**이다.

## 순서

### Phase 1 — 정보만 (지금)

**비자 × 거주 · 비자 × 일 · 비자 × 행정.** 순수 Q&A.

| 왜 이것부터 | |
| --- | --- |
| 콜드스타트가 쉽다 | **혼자 써도 콘텐츠가 된다.** 상대방이 필요 없다 |
| SEO 가 가장 강하다 | 정보성 롱테일. 그리고 [비한국어에서 경쟁이 희박하다](./08-seo-strategy.md) |
| 규제가 가볍다 | 자문 경계 고지(M11)면 된다 |
| BD 고의도 | [팔 수 있는 트래픽](./07-monetization.md) |
| **이미 만들어져 있다** | BE Q&A·태그·페이지네이션 완료 |

### Phase 2 — 리스팅 (밀도 + 법률 검토 후)

거주 매물 · 구인 공고. **둘 다 선행 조건이 있다.**

| | 선행 조건 |
| --- | --- |
| 거주 매물 | 지역 밀도. 공인중개사법 — **게재는 광고, 중개는 자격** |
| 구인 공고 | **출입국관리법 알선 조항 법률 검토.** 직업안정법(유료직업소개 등록) |

리스팅은 `noindex` 로 두고 **정보 페이지만 색인**한다. 죽은 페이지를 만들지 않는다.

### Phase 3 — 물물교환

아래에 따로 적는다. **미루지만 버리지 않는다.**

## 물물교환 — 가장 매력적이고 가장 위험하다

### 좋은 점이 진짜 있다

1. **[재방문 엔진](./08-seo-strategy.md)이다.** SEO 가 AI 요약에 깎이는 상황에서
   "검색은 씨앗, 재방문이 본체"가 전략인데 — **거래는 사람을 다시 오게 한다.**
   정보는 한 번 읽으면 끝이다
2. **외국인만의 사이클이 있다.** 귀국하는 사람이 가구·가전·자전거를 처분하고,
   막 도착한 사람이 그걸 전부 필요로 한다. **한국인 커뮤니티에는 없는 순환**이다
3. **당근에 틈이 있다.** 한국어 전용이고 본인인증이 필요하다

### 그런데 지금 하면 안 되는 이유

| | |
| --- | --- |
| **SEO 가 안 된다** | 유일한 유입 채널인데 기여하지 않는다. 오히려 죽은 페이지를 만든다 |
| **양면 시장** | 커뮤니티 콜드스타트보다 어렵다. 판매자·구매자가 **동시에** 필요하다 |
| **지역 밀도** | 같은 동네여야 거래된다. 전국에 흩어진 100명은 0명과 같다 |
| **분쟁·사기** | 처리할 사람이 필요한데 [인력이 없다](./07-monetization.md#비용이-이제-제약이다) |

### 그래도 넣을 때는 좁게 — "귀국·이사 처분"

물물교환 전체를 열지 않는다. **한 상황으로 좁힌다.**

- **계절성이 있다** — 학기말, 계약 만료, 연말
- **판매자가 절박하다** — 떠나야 하니까 무조건 처분한다.
  즉 **공급이 먼저 생긴다** — 양면 시장에서 한쪽을 먼저 만드는 방법이다
- **묶음으로 나온다** — "집 전체 정리"는 한 건이 여러 거래를 만든다
- **커뮤니티 맥락이 붙는다** — 떠나는 사람의 마지막 글이 후기가 되기도 한다

**양면 시장은 정면으로 열면 안 되고, 한쪽이 절박한 지점을 찾아 거기부터 연다.**

## 빠진 것 — 데이터가 가리키는데 목록에 없다

넷 말고 세 개가 더 있다. 넣는 것을 권한다.

| 주제 | 왜 |
| --- | --- |
| **행정 절차** (외국인등록·건강보험·통신·은행) | **도착 직후 검색량이 가장 크고 콜드스타트가 가장 쉽다.** 답이 정해져 있어 혼자 쓸 수 있다 |
| **한국어·KIIP·TOPIK** | [영주·귀화의 실질 요건](./03-interests-and-jobs.md)이고, [BD Stage 1 상품](./07-monetization.md)과 직결된다 |
| **영주·귀화** | **비치헤드인데 목록에 없다.** "비자문제"에 포함한다면 명시해야 한다 |

마지막이 중요하다 — [ADR-0007](../../50-decisions/0007-settlement-intent-as-primary-axis.md)이
정한 비치헤드가 영주·귀화 준비자다. **그 주제가 1번이어야 한다.**

## Phase 1 시드 콘텐츠 — 실제로 무엇을 쓰나

[콜드스타트를 푸는 유일한 방법](./08-seo-strategy.md#콜드스타트--닭과-달걀)이고,
영업이 없으니 대신할 것이 없다. **좁게, `vi` 우선, 사례 형태로.**

| 축 | 쿼리 형태 예시 |
| --- | --- |
| **영주·귀화** | F-2-7 점수 항목별 계산 · 귀화 필기 준비 · 신청 후 소요 기간 **사례** |
| **비자 × 일** | 이 자격으로 이 일이 되나 · 시간제취업 허가 절차 · **프리랜서가 왜 위험한가** |
| **비자 × 거주** | 체류기간보다 긴 계약이 되나 · 외국인등록 전 계약 · **체류지 변경 신고** |
| **행정** | 외국인등록 준비물 · 건강보험 가입 시점 · 통신·은행 개설 |
| **한국어** | KIIP 단계별 점수 · TOPIK 등급이 어디에 쓰이나 |

**절차 요약이 아니라 사례로 쓴다.** 절차 요약은 AI 요약이 대체하지만
"내 조건으로 어떻게 됐다"는 대체하지 못한다.

## 이 문서가 제품에 요구하는 것

| 요구 | 상태 |
| --- | --- |
| `topic:` 태그 네임스페이스 (`residency` `work` `housing` `admin` `language`) | [태그 설계](../10-features/05-search-and-tagging.md)에 `visa` `region` `school` 만 있다 — **추가 필요** |
| **비자 × 주제 교차 필터** | BE 가 태그 AND 를 지원한다 — **이미 된다** |
| 리스팅 `noindex` | Phase 2 전제 |
| 자문 경계 고지 (M11) | 미정 |

## 열린 질문

- **구인 공고의 출입국관리법 알선 리스크** — 법률 검토를 언제 누가 하는가?
- Phase 2·3 로 넘어가는 **판정 기준**은 무엇인가? "밀도"를 숫자로 말할 수 있어야 한다
- 물물교환의 분쟁 처리를 **사람 없이** 설계할 수 있는가? (거래를 붙이지 않고 연결만 한다면?)
