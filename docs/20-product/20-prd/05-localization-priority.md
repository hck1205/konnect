# 05 · 지원 언어의 순서와 기준

현재 지원: **`en`(기준) · `ko` · `zh` · `vi`** ([ADR-0005](../../50-decisions/0005-multilingual-from-day-one.md))

이 문서는 **다음에 무엇을 왜 추가하는가**를 정한다.

## 언어 하나의 진짜 비용

"사전 파일 하나 추가"가 아니다.

| 비용 | 내용 |
| --- | --- |
| 초기 번역 | 사전 전체 |
| **지속 검수** | 화면이 늘 때마다 **모든 언어**가 늘어난다 |
| **행정 용어 정확도** | R1 영역. 오역이 실제 피해가 된다 — **원어민 검수가 출시 차단 조건** |
| 빈 콘텐츠 | UI 만 번역되고 **질문·답변이 그 언어로 없으면** 첫 화면이 텅 빈다 |

**마지막 항목이 가장 무섭다.** UI 번역은 쉽고 콘텐츠는 어렵다.
언어를 늘리는 것보다 **그 언어 사용자가 그 언어로 글을 쓰게 만드는 것**이 본체다.

→ 그래서 언어 추가는 **세그먼트 진입과 함께**만 한다. UI 만 먼저 늘리지 않는다.

## 선정 기준

1. **모수** — 해당 언어권 체류자 수
2. **대체 언어 없음** — 영어나 한국어로 이미 되는 집단은 후순위
3. **세그먼트 우선순위** — [02](./02-segments-and-priority.md) 의 P0·P1 과 겹치는가
4. **언어 통합 효과** — 여러 국적을 하나로 묶는가

## 현재 4개 언어의 근거

| 언어 | 근거 | 비고 |
| --- | --- | --- |
| `en` | **공통 언어.** 개별 국적 최대가 아니라 나머지를 묶는 최소공통분모 | 미국 180,230 은 부차적 근거다 |
| `ko` | 한국인 도우미·언어교환 상대. 그리고 **원문 병기**의 기준 | |
| `vi` | 베트남 337,183 (2위) · **유학생 1위 115,131 (36.6%)** | **가장 강한 근거를 가진 언어** |
| `zh` | 중국 980,670 (1위) | ⚠️ 아래 참고 |

### `zh` 는 모수가 1위지만 효과는 1위가 아니다

중국 국적 980,670명 중 상당수가 **한국계중국인(조선족)** 이다
(F-4 재외동포 556,208명이 대리 지표). 이들은 **한국어에 불편이 없다.**
게다가 유학생 중 중국은 **줄고 있다** (86,179 → 78,529).

`zh` 를 뺄 이유는 아니다 — 한국어가 안 되는 중국 국적자도 많다.
다만 **`zh` 의 실효 모수는 98만이 아니라 그보다 한참 작다**는 것을 알고 있어야 한다.
`vi` 와 `zh` 에 같은 자원을 쓰는 것은 잘못된 배분이다.

| **2** | `mn` 몽골어 | 몽골 | 유학생 18,992 (4위). **대체 언어가 없다** | 유학 콘텐츠가 찼을 때 |
| 3 | `ne` 네팔어 | 네팔 | 유학생 17,494 (5위) + E-9 | |

**`ja` · `es` 는 넣지 않는다.** 모수·문제밀도 어느 쪽도 근거가 없다.
"흔한 언어라서" 는 기준이 아니다.

## 영어를 기준 언어로 유지하는 이유

`vi` 사용자가 가장 많은데도 기준은 `en` 이다. 이유:

- **폴백 대상**이 필요하다. 번역이 없을 때 떨어질 곳이 하나 있어야 한다
- 나머지 국적(몽골·네팔·인도네시아·필리핀…)을 **하나로 묶는 유일한 언어**다
- 개발·문서·용어의 기준이 하나여야 한다

**기준 언어 ≠ 1순위 투자 대상.** 검수·콘텐츠 투자는 `vi` 가 먼저다.

## 구현이 이미 준비한 것

언어 추가가 **파일 추가로 끝나도록** 되어 있다:

- 복수형은 `Intl.PluralRules` — 언어별 규칙을 우리가 갖고 있지 않다
- 숫자·날짜·목록도 `Intl` (베트남어 천 단위는 마침표: `1.234.567`)
- 누락 키는 **키 그대로 화면에 뜬다** — 빈 문자열이면 못 본다
- `messages.test.ts` 가 사전 간 키 정합성을 검사한다

**언어를 추가할 때 새 사전이 이 테스트를 통과하는 것이 최소 조건이고, 충분조건은 아니다.**
충분조건은 **원어민 검수**다.

## 사용자 콘텐츠의 언어

UI 언어와 **글의 언어는 다른 문제**다.

- 사용자 글은 **번역하지 않는다** (ADR-0003)
- 대신 **작성 언어 태그**를 붙이고 피드에서 필터한다 ([S7](./04-requirements.md))
- 이유: 베트남어 질문이 영어 피드를 덮으면 **양쪽 사용자를 다 잃는다.**
  언어별로 나뉜 피드가 있어야 각 언어권이 자기 임계질량을 만든다
