# 08 · 유입 전략 (SEO)

> **영업이 없으므로 SEO 가 유일한 유입 채널이다.**
> 그러면 이것은 마케팅 문서가 아니라 **생존 문서**다.

## 먼저 나쁜 소식 — 지금 SEO 환경은 예전과 다르다

AI 검색 요약(AI Overviews)이 퍼블리셔 트래픽을 구조적으로 깎고 있다.

| 지표 | 값 | 기간 |
| --- | --- | --- |
| 글로벌 퍼블리셔 트래픽 | **−33%** | 2024-11 → 2025-11 |
| 미국 | **−38%** | 같은 기간 |
| 오가닉 CTR — AI 요약 **있을 때** | **0.61%** | |
| 오가닉 CTR — AI 요약 **없을 때** | 1.62% | |
| AI 요약이 1위 결과 클릭을 줄인 비율 | 34.5% → **58%** | 2025-04 → 2025-12 |
| 트래픽 감소 중 AI 요약·제로클릭 기여분 | **60~75%** | 2026 Q1 감사 기준 |

**"좋은 콘텐츠를 쓰면 검색에서 온다"는 전제가 약해졌다.**
그리고 우리가 다루는 주제 — "F-2-7 점수가 뭔가", "영주권 요건이 뭔가" — 는
**AI 요약이 가장 잘 처리하는 정보성 쿼리**다. 정면으로 맞는다.

### 그래서 결론

**검색을 유일 채널로 두면 안 된다. 검색은 씨앗이고, 재방문이 본체여야 한다.**

```
검색 유입  ──▶  가입·구독  ──▶  재방문(직접 유입)  ──▶  답변자
  깎이는 중                        여기가 자산이다
```

[BD 지표](./07-monetization.md#bd-지표--mau-를-보지-않는다)에 **직접·재방문 비율**을
넣은 이유가 이것이다. 검색 트래픽은 우리가 통제할 수 없고, 재방문은 통제할 수 있다.

## 그럼에도 우리가 이길 수 있는 곳

역풍이 **모든 쿼리에 균일하게 부는 것은 아니다.** 우리에게 유리한 비대칭이 셋 있다.

### 기회 1 — 비한국어·비영어 검색

**한국어로는 이길 수 없다.** `hikorea.go.kr` 같은 정부 사이트가 상위를 먹고,
그 위에 AI 요약이 붙는다. 들어갈 자리가 없다.

**그런데 베트남어·태국어·몽골어로 한국 영주권을 검색하면 상황이 완전히 다르다.**

| | 한국어 | 베트남어 등 |
| --- | --- | --- |
| 정부 공식 콘텐츠 | 있다 (강함) | **거의 없다** |
| 경쟁 | 행정사·블로그 다수 | **희박하다** |
| AI 요약이 인용할 원본 | 많다 | **없다 — 요약할 것이 없으면 요약도 못 한다** |

**이것이 다국어를 처음부터 넣은 결정([ADR-0005](../../50-decisions/0005-multilingual-from-day-one.md))의
진짜 값어치다.** 마케팅 판단이 아니라 **경쟁 회피 판단**이었던 셈이다.

⚠️ 다만 비영어권의 AI 요약 성숙도가 낮을 것이라는 추정은 **확인되지 않았다.**
빠르게 따라올 수 있다. 이 기회는 **영구적이지 않다.**

### 기회 2 — AI 가 만들 수 없는 콘텐츠

AI 요약은 **이미 존재하는 정보를 합친다.** 존재하지 않는 것은 못 만든다.

| AI 가 대체하는 것 | AI 가 못 만드는 것 |
| --- | --- |
| "F-2-7 점수 항목이 무엇인가" | **"내 조건으로 신청했더니 3주 걸렸다"** |
| "영주권 신청 서류 목록" | "이 서류에서 반려당했다" |
| 제도 요약 | **어제 바뀐 제도** |
| 일반론 | **특정 출입국사무소·특정 학교·특정 회사** 사례 |

**전부 UGC 다.** 즉 커뮤니티가 도는 것 자체가 SEO 전략이다 —
콘텐츠를 따로 만드는 게 아니라 **사람들이 쓰게 하는 것**이 콘텐츠 전략이다.

### 기회 3 — 롱테일

"영주권"은 못 이겨도 `F-2-7 점수 한국어 능력 몇 점`,
`귀화 면접 국민선서`, `외국인 전세자금대출 조건` 은 이길 수 있다.
검색량은 작지만 **종류가 무한하고 의도가 뾰족하다** — 그리고
[BD 관점에서 고의도 트래픽](./07-monetization.md)이 정확히 이것이다.

## 우리가 지는 곳 — 인정하고 피한다

| | 왜 지는가 |
| --- | --- |
| 한국어 일반 정보 쿼리 | 정부 사이트 + AI 요약. **자리가 없다** |
| "비자 종류", "한국 생활" 같은 헤드 키워드 | 경쟁 과다, 의도 불명확, 전환 없음 |
| **E-E-A-T** | 비자·법률·금융은 **YMYL**(Your Money Your Life)이다. 검색엔진이 전문성·권위·신뢰를 강하게 요구하는데 **익명 커뮤니티는 구조적으로 불리하다** |

### E-E-A-T 를 구조로 보완한다

익명성은 [포기할 수 없다](./04-requirements.md#wont--지금-명시적으로-안-한다) —
신원 노출이 곧 위험인 사용자가 있다. 대신 **신뢰 신호를 다른 데서 만든다.**

| 신호 | 이미 요구사항에 있는가 |
| --- | --- |
| 답변자의 **체류 연차·자격** 표시 | 프로필 (선택 입력) |
| **평판** — 채택된 답변 수 | S1 |
| **공식 출처 링크** | M10 |
| **작성·갱신 시각** | M9 |
| **정보/자문 경계 고지** | M11 |

**이 다섯이 SEO 요구사항이기도 했다는 것이 이번에 드러났다.**
신뢰를 위해 넣은 것들이 그대로 E-E-A-T 신호다.

## 콜드스타트 — 닭과 달걀

**UGC 가 없으면 색인할 게 없고, 트래픽이 없으면 UGC 가 안 생긴다.**
영업이 없으니 이 고리를 풀 외부 지렛대도 없다.

유일한 방법은 **시드 콘텐츠를 직접 만드는 것**이다. 조건:

1. **비치헤드 주제로 좁힌다** — 영주·귀화 절차. 넓히면 아무 데도 안 뜬다
2. **`vi` 우선** — 기회 1 이 가장 큰 곳
3. **AI 가 못 만드는 형태로** — 절차 요약이 아니라 **사례·후기·구체적 수치**
4. **양보다 완결성** — 얕은 글 100개보다 끝까지 답하는 글 20개

**이것이 유일한 초기 투자다.** 그리고 영업이 없으므로 이 투자를 대신할 것이 없다.

## 기술적 SEO — 이미 된 것과 안 된 것

### 이미 맞게 되어 있다

| | |
| --- | --- |
| **로케일 URL 세그먼트** (`/vi/...`) | 언어별 색인의 전제. 쿠키 방식이었으면 색인이 하나로 뭉개진다 |
| **비로그인 읽기** | 크롤러도 비로그인이다. 로그인 벽이 있으면 색인 자체가 안 된다 |
| `Accept-Language` 협상 → 307 | 사용자 편의. 크롤러에는 영향 없음 |

### 아직 없다 — 해야 할 것

| 항목 | 왜 |
| --- | --- |
| **`hreflang`** | 같은 글의 언어별 판이 서로를 가리켜야 한다. 없으면 **중복 콘텐츠로 묶여 한 언어만 남는다** |
| **`sitemap.xml`** | ⚠️ 아래 참고 — 우리 구조에서는 **선택이 아니다** |
| **구조화 데이터** (`QAPage`) | Q&A 는 전용 스키마가 있다. 리치 결과와 AI 인용 모두에 영향 |
| `canonical` | 태그 필터 조합이 무한한 URL 을 만든다. 정규 URL 을 못 박아야 한다 |
| 언어별 메타·OG | 사전에서 나와야 한다 |
| 필터 URL `noindex` | 조합 폭발을 색인시키면 품질 평가가 깎인다 |
| **허브를 깊을 때만 만든다** | 값이 200개인 축(지역·국적)을 허브로 만들면 **얕은 페이지 200개**가 생긴다. 기준과 목록은 [07-routes](../../30-architecture/07-routes-and-indexing.md) |

### ⚠️ 키셋 페이지네이션이 SEO 에 불리하다

이건 이번에 발견한 실제 문제다.

[커서 기반 페이지네이션](../../30-architecture/03-api-conventions.md)은
사용자에게는 옳다(중복·누락 없음). 그런데 **크롤러는 "다음 커서"를 모른다.**
`?page=2` 같은 열거 가능한 URL 이 없으면 **크롤러가 깊은 목록에 도달하지 못한다.**

선택지:

| 방법 | 평가 |
| --- | --- |
| **`sitemap.xml` 로 모든 상세 URL 을 직접 제공** | **권장.** 목록을 크롤 경로로 쓰지 않는다. 커서 방식을 유지할 수 있다 |
| 목록에 오프셋 페이지 병행 제공 | 크롤러 전용 경로가 생겨 구현이 갈라진다 |
| 태그·주제별 색인 페이지 | sitemap 과 병행하면 좋다. 내부 링크가 깊이를 만든다 |

**결정: sitemap 을 필수 요구사항으로 올린다.** 커서 페이지네이션을 바꾸지 않는다 —
사용자 경험이 옳고, 크롤 경로는 sitemap 이 해결한다.

## AI 검색에 인용되는 것도 목표다

클릭이 줄어도 **AI 요약에 인용되는 것 자체가 자산**이다. 브랜드가 노출되고,
"konnect 에서 봤다"는 직접 유입으로 돌아온다.

인용되려면:

- **구조가 명확해야 한다** — 질문·답변이 마크업으로 구분됨 (`QAPage`)
- **출처가 붙어야 한다** — 공식 링크 (M10)
- **시점이 명시돼야 한다** — 갱신 시각 (M9)

**신뢰를 위해 만든 것이 여기서도 그대로 쓰인다.** 세 번째로 같은 결론이 나왔다.

## 측정

| 지표 | 왜 |
| --- | --- |
| **직접·재방문 비율** | **가장 중요.** 검색 의존도를 낮추는 것이 생존 전략이다 |
| 언어별 오가닉 세션 | 기회 1 이 실제로 작동하는가 |
| 색인된 URL 수 vs 발행 수 | sitemap·크롤 경로가 작동하는가 |
| 롱테일 쿼리 비율 | 헤드 키워드에 헛심 쓰고 있지 않은가 |
| 노출 대비 클릭률 추이 | AI 요약 잠식이 어디까지 왔는가 |

**MAU 를 목표로 삼지 않는다.** 검색 트래픽은 우리가 통제하지 못하는 변수다.

## 열린 질문

- **시드 콘텐츠를 누가 만드는가?** 영업이 없듯 콘텐츠 인력도 없다면
  이 계획 전체가 시작되지 않는다
- 비영어권 AI 요약 성숙도가 실제로 낮은가? **확인되지 않은 가정 위에 기회 1 이 서 있다**
- 익명성과 E-E-A-T 의 균형점 — 구조적 신호만으로 YMYL 을 통과할 수 있는가?
- 검색 의존을 낮추려면 재방문 유인이 필요한데, **알림(S4)이 그것으로 충분한가?**
