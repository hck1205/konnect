# 02 · 세그먼트와 우선순위

[01-market-data](./01-market-data.md) 의 숫자를 **누구를 먼저 볼 것인가**로 옮긴다.

## 모수가 큰 것과 도달할 수 있는 것은 다르다

가장 흔한 실수는 **인구 1위를 타깃 1위로 놓는 것**이다. 여기서는 틀린다.

네 축으로 본다.

| 축 | 묻는 것 |
| --- | --- |
| **모수** | 몇 명인가 |
| **도달가능성** | 우리 채널(웹·검색)로 닿는가. 기기·시간·언어·신원노출 부담 |
| **문제밀도** | 해결 안 된 문제가 얼마나 촘촘한가. **대안이 이미 있으면 낮다** |
| **잔존기간** | 얼마나 오래 머무는가. 짧으면 커뮤니티에 남지 않는다 |

## 세그먼트 평가

| 세그먼트 | 대표 자격 | 모수 (2025-12) | 도달 | 문제밀도 | 잔존 | 우선 |
| --- | --- | ---: | --- | --- | --- | --- |
| **A 유학생** | D-2 · D-4 | 308,838 (+17.1%) | **높음** | **높음** | 길다 | **P0** |
| **B 졸업 후 전환자** | D-10 → E-7 | A 의 62.8% | **높음** | **높음** | 매우 길다 | **P0** |
| C 전문인력·영어권 | E-7 · F-2 | ~180,230 (미국 기준) | 높음 | 중간 | 길다 | P1 |
| D 비전문취업 노동자 | E-9 · H-2 | 594,047 의 다수 | **낮음** | **매우 높음** | 중간 | P2 |
| E 결혼이민·가족 | F-6 · F-5 | 188,105 | 중간 | 높음 | 매우 길다 | P2 |
| F 재외동포 | F-4 | 556,208 | 중간 | **낮음** | 길다 | P3 |
| G 여행자·단기 | B-2 · K-ETA | ~640,000 | 높음 | 낮음 | **매우 짧다** | 제외 |

### 왜 인구 1위(중국·동포)가 P3 인가

중국 국적 980,670명은 압도적 1위다. 그런데:

- 상당수가 **한국계중국인(조선족)** 이고 — F-4 재외동포 556,208명이 그 대리 지표다 —
  **한국어에 불편이 없다**
- 그래서 네이버 카페·밴드 등 **한국어 커뮤니티를 이미 쓴다.** 대안이 존재한다
- 유학생 통계에서 **중국은 절대 수가 줄고 있다** (86,179 → 78,529)

**문제밀도가 낮다.** 모수가 크다고 우리가 줄 게 있는 것은 아니다.
konnect 의 핵심 가치는 "한국어로만 존재하는 정보를 다른 언어로 옮기는 것"인데,
이 집단은 그 가치가 필요 없다.

### 왜 문제가 가장 심각한 D(E-9 노동자)가 P2 인가

**문제밀도는 전 세그먼트 중 1위다.** 조사에서도 직장 내 어려움이
"업무 속도가 빠름 · 한국인 동료와의 갈등 · **작업 중 부상**" 으로 나온다. 부상이 상위 3위다.

그런데 웹 커뮤니티로 닿기가 어렵다:

| 장벽 | 내용 |
| --- | --- |
| 기기 | 스마트폰 단독. 데스크톱 기준 UI 는 쓰이지 않는다 |
| 시간 | 취업자 비중 99.7% — **거의 전원이 일한다.** 장시간·교대 근무 |
| 언어 | 한국어·영어 모두 낮은 비중이 크다. 자국어 아니면 진입 불가 |
| 신원 | 고용주 관련 질문은 **신원이 드러나면 보복 위험**이 있다 |
| 기존 채널 | Zalo · 자국어 Facebook 그룹 등 **폐쇄형 채널이 이미 자리 잡았다** |

**P2 로 두는 것은 "덜 중요해서"가 아니라 "지금 구조로는 못 닿아서"다.**
닿으려면 모바일 우선 + 자국어 + **익명 보장**이 전제다.
그 셋이 준비되기 전에 이 세그먼트를 타깃이라고 말하면 거짓말이 된다.
→ [06-risks](./06-risks-and-open-questions.md) 의 열린 질문으로 남긴다.

### 왜 A(유학생)가 P0 인가

네 축이 전부 좋은 **유일한** 세그먼트다.

- **모수 30만, 증가율 +17.1%** — 유일한 두 자릿수 성장
- **도달가능성 최상** — 캠퍼스 네트워크·노트북·검색 습관이 기본값이다
- **문제밀도 높음** — 입학·비자·기숙사·아르바이트 허가·건강보험이 **동시에** 걸린다.
  그리고 이 정보는 **학교마다 다르고 한국어로만 있다**
- **잔존기간 길다** — 최소 2~4년

### A 와 B 는 같은 사람이다

**유학생의 62.8%가 졸업 후 한국 체류를 계획한다.**

이것이 이 서비스의 구조를 정한다. A 를 잡으면 B 는 **이탈이 아니라 성숙**이다.
그리고 성숙한 B 가 **새 A 의 질문에 답한다** — 커뮤니티가 자급하는 회로가 여기서 생긴다.

```
A 유학생  ──2~4년──▶  B 전환자(D-10→E-7)  ──▶  C/E 정착
   ▲                         │
   └───────  답변한다  ───────┘
```

**"졸업 후 진로"를 이탈 지점이 아니라 전환 지점으로 설계한다.**
[여정 문서](../03-user-journeys.md)의 전제를 이 회로에 맞춘다.

## 국적 우선순위 — 세그먼트와 곱한다

유학생(P0) 안에서 다시 국적을 본다 (2026-02):

| 국적 | 유학생 수 | 유학생 중 | 판단 |
| --- | ---: | ---: | --- |
| **베트남** | 115,131 | **36.6%** | **1순위.** 성장하는 모든 축의 교집합 |
| 중국 | 78,529 | 25.0% | 감소 중 + 한국어 대안 보유 → 우선순위 낮춤 |
| 우즈베키스탄 | 20,609 | 6.6% | 러시아어권. 3국(우즈벡·카자흐·러시아) 합산 시 유의미 |
| 몽골 | 18,992 | 6.0% | |
| 네팔 | 17,494 | 5.6% | |

**결론: 1차 타깃은 "베트남 국적 유학생 및 졸업 후 전환자"다.**

영어는 여전히 기준 언어지만 — 나머지 국적을 하나로 묶는 **공통 언어**이기 때문이지,
가장 큰 사용자 집단의 언어이기 때문이 아니다.
[05-localization-priority](./05-localization-priority.md) 가 이 구분을 다룬다.

## 지역 전제를 바꾼다

수도권 밖이 **43.2%** 이고, 밀도 최상위는 서울이 아니라
**안산(16.1%) · 영암(21.1%) · 음성(19.9%)** 같은 산업단지 배후 도시다.

- 지역 태그를 **서울 자치구 중심으로 만들지 않는다.** 시·군 단위가 1급 시민이다
- "서울 기준" 기본값(예: 지역 필터 초기값)을 두지 않는다
- 다만 **P0 인 유학생은 대학 소재지를 따른다** — 지역보다 **학교**가 더 강한 축이다.
  지역 필터와 학교 필터는 **다른 축**이며 둘 다 필요하다
