# 02 · 세그먼트와 우선순위

[01-market-data](./01-market-data.md) 의 숫자를 **누구를 먼저 볼 것인가**로 옮긴다.

> 축이 바뀌었다: **체류 목적**이 아니라 **정주 의도**로 자른다
> ([ADR-0007](../../50-decisions/0007-settlement-intent-as-primary-axis.md)).

## 축은 넷, 무게는 같지 않다

| 축 | 묻는 것 | 무게 |
| --- | --- | --- |
| **잔존기간** | 얼마나 오래 머무는가 — **여기서 살 사람인가** | **최우선** |
| 문제밀도 | 해결 안 된 문제가 얼마나 촘촘한가. **대안이 이미 있으면 낮다** | 높음 |
| 도달가능성 | 우리 채널(웹·검색)로 닿는가 | 높음 |
| 모수 | 몇 명인가 | **가장 낮음** |

**모수를 가장 낮게 둔다.** 커뮤니티는 사람이 **남아야** 성립하고,
남지 않는 사람 100만보다 남는 사람 10만이 낫다.

## 비치헤드: 영주·귀화 준비자

모수만 보면 결혼이민(188,105)이 커 보인다. 커뮤니티 **시작점**으로는 A 가 낫다.

| | C 결혼이민 | **A 영주·귀화 준비자** |
| --- | --- | --- |
| 민감도 | **매우 높음** — 배우자 갈등·가정폭력·이혼 시 체류자격 상실 | **낮음** — 절차·서류·점수 |
| 기존 강자 | **다문화가족지원센터** (전국 200여 개, 정부 예산, 통역·상담 무료) | 없음. 행정사 유료 상담뿐 |
| Q&A 적합성 | 낮음 — 정답이 없는 **상담** 영역 | **높음 — 정답이 있고 경험자가 답한다** |
| 국적 의존 | 높음 | **없음** |

### A 를 고른 네 가지 이유

1. **"정주 의도"의 정의 그 자체다.** 영주권을 신청한다는 건 여기서 살겠다는 선언이다
2. **검색 의도가 극도로 뾰족하다** — `F-2-7 점수 계산` · `귀화 필기시험 기출` · `영주권 서류`
3. **답변자가 떠나지 않는다.** 영주권자는 영구히 남는다 —
   커뮤니티가 가장 얻기 어려운 자원이고, 여기서만 공짜로 생긴다
4. **하나의 콘텐츠가 모든 정주 세그먼트에 닿는다.** 결혼이민도 전문인력도 동포도
   졸업 후 잔류자도 **전부 이 관문을 지난다.** 언어별 임계질량을 각각 넘지 않아도 된다

**규모**: 매년 3.6만 명이 통과하고(귀화·국적회복 15,381 + 영주 상주인구 증가 21,000),
준비 기간이 1~3년이라 **동시에 준비 중인 사람은 10만 명 단위**다.

### 확장 순서

```
A 영주·귀화 준비자  ──▶  B 정착 취업자
        │                    │
        ├──▶  D 졸업 후 잔류자  (같은 관문을 지난다)
        └──▶  C 결혼이민·가족   (안전장치 완비가 전제)
```

**C 는 비치헤드가 아니라 확장 대상이다.** 영주 준비로 들어온 사람이
자녀 교육·주택을 이야기하게 되는 순서가 자연스럽다. 거꾸로는 위험하다.


## 확장 경로 — 유학생은 언제 돌아오는가

**"나중에 범위를 넓힌다"는 것은 순서가 있다는 뜻이다.** 아무 때나 넓히는 것이 아니다.

```
지금            A 영주·귀화 준비자  ─┐
                B 정착 취업자      ─┤→ 커뮤니티 임계질량
안전장치 완비 후  C 결혼이민·가족    ─┘
                                    │
대학 B2B 계약 시  G 유학생 ──────────┘  ← 여기서 열린다
```

유학생 확장의 조건은 **모수도 요청도 아니라 지불 주체**다.

| | 유학생 |
| --- | --- |
| B2C 수익화 | **거의 불가** — 지불 능력이 없고 고단가 의사결정도 없다 |
| B2B 수익화 | **가능** — 대학이 유학생 유치·정착 지원에 예산을 쓴다 |

즉 유학생은 **대학이라는 지불 주체가 붙는 순간(Stage 4)** 에 열린다.
그 전에 열면 트래픽만 늘고 수익 라인이 따라오지 않는다
([07-monetization](./07-monetization.md#stage-4--b2b-월-20만-이후)).

**그리고 그때는 이미 D(졸업 후 잔류자)가 쌓여 있다** — 유학생의 질문에
답할 사람이 준비된 상태로 여는 것이다. 순서가 이렇게 되는 것이 우연이 아니다.

## 비타깃으로 내린 것

### G 유학생(재학 중) — 타깃에서 뺀다

이전 판([ADR-0006](../../50-decisions/0006-audience-priority-from-population-data.md))에서는
1차 타깃이었다. 정주 의도를 최우선 축으로 두면서 내렸다.

- 재학 중에는 **정주 의도가 미정**이다 (졸업 시점에 62.8%가 잔류를 택한다)
- 관심사가 겹치지 않는다 — 입학·기숙사·아르바이트는 **1~2년 시야**,
  정주자는 영주권·세금·자녀 교육의 **10년 시야**다
- 둘을 한 제품에 담으면 **피드가 갈라진다**

**졸업 후 잔류를 택한 시점에 D 로 들어온다.** 버리는 것이 아니라 **입구를 뒤로 옮기는 것**이고,
세그먼트 전체는 위 확장 경로에 따라 **대학 B2B 와 함께** 돌아온다.

### E 재외동포 — 모수 1위지만 문제밀도가 낮다

F-4 재외동포 556,208명 중 상당수가 한국계중국인이고 **한국어에 불편이 없다.**
네이버 카페 등 대안을 이미 쓴다. konnect 의 핵심 가치가 필요 없는 집단이다.

### F 비전문취업 노동자 — 문제는 1위인데 닿지 않는다

직장 내 어려움 상위 3위에 **작업 중 부상**이 들어간다. 문제밀도는 전 세그먼트 1위다.

| 장벽 | 내용 |
| --- | --- |
| 기기 | 스마트폰 단독 |
| 시간 | 취업자 비중 99.7% — **거의 전원이 일한다.** 장시간·교대 |
| 언어 | 자국어 아니면 진입 불가 |
| 신원 | 고용주 관련 질문은 **신원이 드러나면 보복 위험** |
| 기존 채널 | Zalo · 자국어 Facebook 그룹이 이미 자리 잡았다 |

**P3 인 것은 "덜 중요해서"가 아니라 "지금 구조로는 못 닿아서"다.**
닿으려면 모바일 우선 + 자국어 + **익명 보장**이 전제인데,
익명은 정보 신뢰(R2)와 충돌한다.
→ [06-risks](./06-risks-and-open-questions.md) 의 열린 질문으로 남긴다.

### G 여행자 — 잔존기간이 없다

포화 시장이고 우리가 이길 이유가 없다.

## 지역 전제

수도권 밖이 **43.2%**, 밀도 최상위는 서울이 아니라
**안산(16.1%) · 영암(21.1%) · 음성(19.9%)** 같은 산업단지 배후 도시다.

- 지역 축은 **시·군 단위가 1급 시민**이다. 서울 자치구 중심으로 만들지 않는다
- "서울"을 기본값으로 두지 않는다
- 정주자는 유학생과 달리 **학교가 아니라 지역에 묶인다.**
  집을 사고 아이를 학교에 보내는 사람에게 지역은 가장 강한 축이다
