# 07 · 수익 파이프라인 (BD)

> **제약: 영업 인력이 없다.** 유입은 순수 SEO + 커뮤니티다.
> 이 제약이 수익 라인의 절반을 지운다. 지워진 것을 지워진 채로 적는다.

## 전제: 트래픽이 아니라 **의사결정 순간**을 판다

일반 커뮤니티의 수익은 **트래픽 × 낮은 단가(CPM)** 다. 그 게임은 규모로만 이긴다.
이 오디언스에서는 다른 게임을 할 수 있다.

| 자산 | 왜 비싼가 |
| --- | --- |
| **도달 불가 오디언스** | 은행·통신·보험·부동산이 외국인에게 닿을 채널이 **사실상 없다** |
| **고단가·비가역 의사결정** | 정주자는 **집을 사고 대출을 받고 보험에 든다.** 유학생에게는 없는 수요다 |
| **긴 LTV** | 10년 이상 거주한다 |

**그래서 CPM 이 아니라 CPA/CPS 로 판다.**
[ADR-0007](../../50-decisions/0007-settlement-intent-as-primary-axis.md) 의 타깃 결정은
BD 축으로 다시 계산해도 같은 답이 나온다 — 유학생은 지불 능력도 고단가 의사결정도 없다.

## 영업이 없다는 제약이 무엇을 지우는가

**거의 모든 고단가 라인은 영업 사업이었다.** 정직하게 지운다.

| 라인 | 영업 필요 | 상태 |
| --- | --- | --- |
| ~~공공 용역 (지자체 다국어 정보 위탁)~~ | 조달·제안·심사 | **불가.** 트래픽 0 에서 유일한 답이었는데 사라졌다 |
| ~~금융사 직접 제휴 (대출·보험 리드)~~ | B2B 계약 | **인바운드 전까지 불가** |
| ~~기업 채용 · 대학 B2B~~ | B2B 영업 | **인바운드 전까지 불가** |
| ~~비자 전문가 연결~~ | 제휴 + **법률 검토** | 불가 (원래도 검토 전 보류) |
| **셀프서브 제휴** | **없음 — 온라인 가입** | **가능** |
| **광고 네트워크** | **없음** | **가능** |
| **자체 디지털 상품** | 없음 (제작 비용은 든다) | 가능 |
| **인바운드 광고 문의** | 없음 — **트래픽이 영업을 대신한다** | 규모 도달 시 |

**결과: "언제 무엇을 파나"의 문제가 "언제 인바운드가 오나"의 문제로 바뀐다.**

## 살아남는 라인

### L1 — 글로벌 셀프서브 제휴 (지금 시작 가능)

**국내 제휴사는 영업을 요구하지만, 글로벌 제휴 프로그램은 온라인 셀프 가입이다.**
그리고 우연히도 **우리 오디언스와 더 잘 맞는다** — 외국인 대상 서비스이기 때문이다.

| 카테고리 | 왜 맞는가 |
| --- | --- |
| **해외 송금** | 정주자·근로자 공통 수요. 글로벌 송금사는 제휴 프로그램이 표준이고 셀프 가입이다 |
| **어학 (온라인 튜터·강의)** | **KIIP·TOPIK 이 영주·귀화 요건**이라 관심사가 곧 상품이다 |
| **여행자보험·해외 카드** | 입국 초기 수요 |

⚠️ **국내 커머스 제휴(쿠팡파트너스 등)는 맞지 않는다.** 오디언스와 무관한 링크를
붙이면 전환도 안 나오고 신뢰만 깎인다. 트래픽이 있다고 아무거나 붙이지 않는다.

### L2 — 광고 네트워크 (바닥)

애드센스류. 영업 0, 언어 무관.
**단가가 낮아 이것만으로는 운영비가 안 나온다.** 바닥을 깔아 두는 용도다.

다만 **금융·비자 키워드는 CPM 이 높은 편**이라 일반 커뮤니티보다는 낫다.

### L3 — 자체 디지털 상품 (트래픽 후)

서류 체크리스트·가이드·템플릿. 영업은 필요 없지만 **제작 비용이 든다.**
UGC 가 쌓인 뒤 "많이 물어보는 것"을 정리하는 형태가 비용 대비 효율이 낫다.

### L4 — 인바운드 (전환점)

**트래픽이 충분해지면 광고주가 먼저 온다.** 이때 비로소
금융·교육·부동산 직접 제휴가 열린다 — 영업 없이.

**이것이 이 계획의 유일한 진짜 도약 지점이다.** 그전까지는 L1+L2 로 버틴다.

## 규제 — 선은 그대로다

영업이 없어도 규제는 없어지지 않는다.

| 라인 | 관련 법 | 선 |
| --- | --- | --- |
| 비자 전문가 | 행정사법 · 출입국민원 대행기관 관리지침 | [등록 대행기관](https://www.immigration.go.kr/bbs/immigration/211/578730/artclView.do)만 대행 가능. **알선 여부 법률 검토 필요** |
| 금융 (송금·계좌·대출·보험) | 금융소비자보호법 | **광고는 가능, 판매대리·중개는 등록** |
| 부동산 | 공인중개사법 | 중개는 자격, 광고 플랫폼은 가능 |
| 채용 | 직업안정법 | 공고 게재는 광고, 유료직업소개는 등록 |
| **제휴 링크 표시** | **표시광고법 · 공정위 추천보증 심사지침** | **대가를 받았다는 사실을 명확히 표시해야 한다** |
| 리드 전달 | 개인정보보호법 | 제3자 제공 동의 별도 |

**공통 원칙: "정보 제공·광고"와 "중개·알선"의 선을 넘지 않는다. 애매하면 하지 않는다.**

제휴 링크는 규제가 가벼워 보이지만 **표시 의무가 있다.** 그리고 우리 경우엔
[사용자의 언어로](#신뢰와의-충돌) 표시해야 실제로 표시한 것이 된다.

## 신뢰와의 충돌

**커뮤니티는 상업적으로 오염되면 죽는다.** 우리 경우엔 그보다 나쁘다 —
비자·영주 정보는 [R1 영역](../../10-domain/10-visa-immigration/03-content-and-risk-policy.md)이라
**광고주 이해관계가 답변에 섞이면 사용자에게 실제 피해가 난다.**

원칙 셋을 제품에 박는다:

1. **답변에 광고를 섞지 않는다.** 광고는 답변 흐름과 **물리적으로 분리된 자리**에만
2. **전문가 답변자는 배지로 표시하고 이해관계를 공개한다**
3. **광고·제휴는 그렇다고 표시한다 — 사용자의 언어로.**
   한국어로만 "광고"라고 쓰면 표시하지 않은 것과 같다

**영업이 없을 때 이 원칙이 더 중요해진다.** 수익이 급하면 원칙이 먼저 무너지는데,
이 오디언스에서 신뢰를 잃으면 대체 유입 경로가 없다.

## 최대 기회이자 최대 리스크 — 요건 계산기

사용자가 영주권 점수를 계산하는 순간 **소득·학력·한국어 등급·체류기간**을 입력한다.
완벽한 세그먼테이션이면서 **민감정보**다.

**원칙: 계산은 클라이언트에서 하고 저장하지 않는다.**
저장하면 개인정보 문제가 생기고, 그보다 먼저 **신뢰가 무너진다.**
저장 없이 "결과에 따라 관련 정보를 그 자리에서 보여주는 것"은 가능하다.

계산기는 [C6 요구사항](./04-requirements.md)이고 **틀리면 그 자체가 R3**이므로
갱신 책임자가 정해진 뒤에만 만든다.

## 비용이 이제 제약이다

**영업이 없으면 손익분기가 멀다.** 그러면 **비용 구조가 생존을 결정한다.**

| 비용 | 문제 |
| --- | --- |
| 서버·인프라 | 트래픽 대비 낮게 유지 가능 (정적 렌더·캐시) |
| **번역 원어민 검수** | **[출시 차단 조건](./05-localization-priority.md)인데 지속 비용이다** |
| 콘텐츠 시드 | 초기 UGC 를 직접 만들어야 한다 ([08-seo](./08-seo-strategy.md)) |
| 신고 처리 인력 | [ADR-0004](../../50-decisions/0004-direct-messages-with-safety-gates.md) 가 요구한다 |

### 검수 비용과 안전 인력이 수익과 충돌한다

이건 실제 충돌이고, 답이 아직 없다.

- 4개 언어 검수를 지속할 재원이 없다 → **지원 언어를 줄이거나**,
  **R1 콘텐츠만 검수하거나**, **커뮤니티 검수(사용자 번역 제안)** 로 바꿔야 한다
- DM 안전장치는 **신고 처리 인력**을 요구한다. 사람이 없으면
  **DM 을 열지 않는 것**이 유일하게 정직한 선택이다

**돈이 없으면 기능을 줄이는 것이 맞다. 안전장치를 줄이는 것이 아니다.**

## BD 지표 — MAU 를 보지 않는다

| 지표 | 정의 | 왜 |
| --- | --- | --- |
| **고의도 세션 비율** | 영주·대출·주거·교육 관련 세션 / 전체 | 팔 수 있는 트래픽의 비율 |
| **체류 연차 분포** | 3~5년차 비중 | **수익화 가능 인구.** 이 구간이 결심하고 지출한다 |
| **직접·재방문 비율** | 검색 외 유입 | **AI 검색 시대의 생존 지표** ([08-seo](./08-seo-strategy.md)) |
| 제휴 전환율 | 클릭 → 가입 | 낮으면 오디언스와 안 맞는 상품이다. 빼야 한다 |
| 인바운드 문의 수 | 광고주가 먼저 연락한 건수 | **L4 도약 지점의 선행 지표** |

## 이 문서가 제품에 요구하는 것

| 요구 | 어디에 |
| --- | --- |
| 광고 슬롯을 **답변과 분리된 레이아웃**으로 | 디자인 시스템 |
| **다국어 광고·제휴 표시 문구** | i18n 사전 |

| 체류 연차·자격 **선택 입력** | 프로필 — 민감정보 취급 |
| 답변자 배지·이해관계 공개 | [평판](../10-features/04-profiles-and-reputation.md) |

## 열린 질문

- **손익분기까지 무엇으로 버티는가?** 영업이 없으면 L4(인바운드)까지 매출이 거의 없다.
  운영비 부담 주체가 정해져 있는가?
- **번역 검수 비용**을 어떻게 감당하는가? 못 하면 지원 언어를 줄여야 한다
- **신고 처리 인력**이 없으면 DM 을 열 수 있는가? (답: 열 수 없다)
- 인바운드가 오는 트래픽 규모는 얼마인가? 이 계획 전체가 그 숫자에 걸려 있는데 **모른다**

## 하지 않는 것

| | 이유 |
| --- | --- |
| **데이터 판매·제공** | 체류자격·소득은 민감정보다. 한 번 하면 신뢰가 영구히 깨진다 |
| 답변 형태의 광고 | 위 원칙 1 |
| 계산기 입력값 저장·타게팅 | 위 요건 계산기 원칙 |
| 오디언스와 무관한 제휴 (국내 커머스) | 전환도 안 나오고 신뢰만 깎인다 |
| 등록 없이 중개·알선 | 규제 표 |
