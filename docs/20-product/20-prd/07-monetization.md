# 07 · 수익 파이프라인 (BD)

> 이 문서는 **무엇을 팔 수 있는가**를 정한다.
> 기능 우선순위([04-requirements](./04-requirements.md))와 지표([05-metrics](../05-metrics.md))가
> 여기에 종속된다 — 팔 수 없는 것을 만드는 데 시간을 쓰지 않기 위해서다.

## 전제: 트래픽이 아니라 **의사결정 순간**을 판다

일반 커뮤니티의 수익은 **트래픽 × 낮은 단가(CPM)** 다. 그 게임은 규모로만 이긴다.
우리는 그 게임을 하지 않는다.

이 오디언스의 가치는 셋에서 나온다:

| 자산 | 왜 비싼가 |
| --- | --- |
| **도달 불가 오디언스** | 은행·통신·보험·부동산이 외국인에게 닿을 채널이 **사실상 없다.** 한국어 광고는 안 닿고, Facebook 그룹·Zalo 에는 광고를 붙일 수 없다 |
| **고단가·비가역 의사결정** | 정주자는 **집을 사고 대출을 받고 보험에 든다.** 유학생에게는 없는 수요다 |
| **긴 LTV** | 10년 이상 거주한다. 한 번 획득하면 오래 간다 |

**그래서 CPM 이 아니라 CPA/CPS 로 판다.** 같은 트래픽에서 나오는 단가가 자릿수로 다르다.

### 타깃 결정이 BD 관점에서도 맞다

[ADR-0007](../../50-decisions/0007-settlement-intent-as-primary-axis.md) 이
정주 의도를 최우선 축으로 삼은 것은 커뮤니티 논리(잔존기간)에서 나온 결정이었다.
BD 축으로 다시 계산해도 **같은 답이 나온다**:

| | 유학생 | **정주자** |
| --- | --- | --- |
| 지불 능력 | 낮음 | **있음** |
| 고단가 의사결정 | 없음 (월세·통신) | **대출·주택·보험·비자** |
| LTV | 2~4년 | **10년+** |
| B2C 수익화 | 거의 불가 | 가능 |
| B2B 지불 주체 | **대학** | 지자체 · 금융사 · 기업 |

**유학생 확장이 BD 적으로 말이 되는 시점은 대학이라는 지불 주체가 붙을 때다.**
B2C 로는 유학생이 돈이 되지 않지만, **대학은 유학생 유치·관리에 예산을 쓴다.**
그래서 유학생 확장은 [Stage 4](#stage-4--b2b-월-20만-이후) 와 함께 온다 — 순서가 있다.

## 진짜 질문은 "무엇을 팔까"가 아니다

거의 모든 수익 라인이 **트래픽 임계점을 넘어야 시작된다.** 그런데 정주자에게는
입학 시즌 같은 유입 주기가 없어 초기 성장이 완만하다([06-risks R1](./06-risks-and-open-questions.md)).

**BD 관점의 진짜 질문은 "트래픽 없는 첫 12개월을 무엇으로 버티는가"다.**
답은 하나뿐이다 — **공공 용역**. 아래 Stage 0.

## 수익 라인 — 성숙도 순서

### Stage 0 — 공공 용역 (트래픽 0에서 가능)

**무엇을**: 지자체 외국인주민 대상 **다국어 정보 제공·커뮤니티 운영 위탁**

거의 모든 지자체가 「외국인주민 지원 조례」를 갖고 있고 관련 예산이 편성된다.
그리고 [밀도가 높은 지자체가 명확하다](./01-market-data.md#지역-분포) —
**안산(16.1%) · 영암(21.1%) · 음성(19.9%) · 화성 · 시흥**.

**왜 지금 되는가**: 트래픽이 아니라 **역량**을 판다.
다국어 구조와 정보 구조화는 [이미 만들어져 있다](./04-requirements.md).

| 좋은 점 | 비용 |
| --- | --- |
| 트래픽 없이 매출이 난다 | **영업 사이클이 길다** (조달·공고·심사) |
| 규제 리스크가 없다 | 사업 성격이 용역에 끌려갈 위험 |
| 공공 레퍼런스가 이후 모든 영업의 신뢰가 된다 | 제품 로드맵과 어긋나는 요구가 들어온다 |
| 지역 콘텐츠가 **제품 자산으로 남는다** | |

**마지막 줄이 핵심이다.** 용역으로 만든 지역 정보가 제품에 남지 않으면
그냥 외주다. 계약 시 **산출물 소유·재사용 권리**를 반드시 확보한다.

### Stage 1 — 교육 제휴 (월 1만 방문)

**무엇을**: 한국어 · **KIIP(사회통합프로그램)** · TOPIK · 귀화 필기 대비

**왜 첫 상업 수익원인가**: **비치헤드의 관심사가 곧 상품이다.**
KIIP 이수와 TOPIK 등급은 [영주·귀화의 실질 요건](./03-interests-and-jobs.md)이다 —
"점수가 모자라면 무엇을 해야 하나"의 답이 그대로 교육 상품이다.

- 규제 리스크: **낮음**
- 단가: 중간 (CPA)
- 신뢰 훼손: 낮음 — 사용자가 실제로 필요로 하는 것이다

### Stage 2 — 금융 진입 (월 5만)

**무엇을**: 송금 → 계좌·체크카드 → 신용카드

소액해외송금업 제휴는 시장이 이미 성숙해 있고 가입당 수수료 구조가 표준이다.
계좌·카드는 은행들이 외국인 고객 유치에 적극적이다.

- 규제: **금융소비자보호법** — **광고와 중개의 선**을 넘지 않는다.
  단순 광고·정보 제공은 가능하나 **판매대리·중개는 등록이 필요**하다
- 단가: 중간~높음

### Stage 3 — 고단가 리드 (월 20만)

**무엇을**: 주택담보·전세 대출 · 보험 · 부동산 중개

**정주자만의 수요다.** 유학생 타깃이었으면 이 라인이 통째로 없다.

- 규제: 금소법 + **공인중개사법**(중개행위는 자격 필요, 광고 플랫폼은 가능)
- 단가: **최고**
- 신뢰 훼손 위험: **높음** — 아래 원칙을 반드시 건다

### Stage 4 — B2B (월 20만 이후)

**무엇을**:
- **기업** — 외국인 채용 공고, E-7 스폰서 기업 매칭
- **대학** — 유학생 유치·정착 지원 (**여기서 유학생 세그먼트가 열린다**)

- 규제: **직업안정법** — 공고 게재는 광고, **유료직업소개는 등록 필요**

### 별도 — 비자 전문가 연결 (법률 검토 전까지 하지 않는다)

가장 직관적이고 단가가 높다. **그리고 가장 위험하다.**

출입국 민원(비자·체류자격 변경·연장) 대행은 **출입국·외국인청에 등록한
변호사·행정사**(법인·합동사무소 포함)만 할 수 있다. 법무부가
[등록 대행기관 현황을 공개](https://www.immigration.go.kr/bbs/immigration/211/578730/artclView.do)한다.

| 할 수 있어 보이는 것 | 검토가 필요한 것 |
| --- | --- |
| 등록 대행기관 **디렉터리** (공개 정보다) | **리드 판매** — 알선에 해당하는가 |
| 광고 게재 | **성공보수 배분** — 동업·수수료 분배 문제 |
| "복잡하면 전문가에게" 안내 | 상담 예약 중개 |

⚠️ **법률 검토 없이 진행하지 않는다.** [행정사법](https://www.law.go.kr/)과
[출입국민원 대행기관 관리지침](https://www.law.go.kr/admRulSc.do?query=%EC%B6%9C%EC%9E%85%EA%B5%AD%EB%AF%BC%EC%9B%90+%EB%8C%80%ED%96%89%EA%B8%B0%EA%B4%80+%EA%B4%80%EB%A6%AC%EC%A7%80%EC%B9%A8)
확인이 선행 조건이다. 이 표의 왼쪽 칸도 **"할 수 있어 보이는 것"**이지 결론이 아니다.

## 규제 요약

| 라인 | 관련 법 | 선 |
| --- | --- | --- |
| 비자 전문가 | 행정사법 · 출입국민원 대행기관 관리지침 | 등록 대행기관만 대행 가능. **알선 여부 검토 필요** |
| 금융 (송금·계좌·대출·보험) | 금융소비자보호법 | **광고는 가능, 판매대리·중개는 등록** |
| 부동산 | 공인중개사법 | 중개는 자격, **광고 플랫폼은 가능** |
| 채용 | 직업안정법 | 공고 게재는 광고, **유료직업소개는 등록** |
| 리드 전달 전반 | 개인정보보호법 | **제3자 제공 동의**가 별도로 필요 |

**공통 원칙: "정보 제공·광고"와 "중개·알선"의 선을 넘지 않는다.**
넘으려면 해당 등록·자격을 갖춘 뒤에 넘는다. 애매하면 하지 않는다.

## 신뢰와의 충돌 — 이게 진짜 리스크다

**커뮤니티는 상업적으로 오염되면 죽는다.** 그리고 우리 경우엔 그보다 나쁘다 —
비자·영주 정보는 [R1 영역](../../10-domain/10-visa-immigration/03-content-and-risk-policy.md)이라
**광고주 이해관계가 답변에 섞이면 사용자에게 실제 피해가 난다.**

원칙 셋을 제품에 박는다:

1. **답변에 광고를 섞지 않는다.** 광고는 답변 흐름과 **물리적으로 분리된 자리**에만 둔다.
   "추천 답변" 형태의 광고는 만들지 않는다
2. **전문가 답변자는 배지로 표시하고 이해관계를 공개한다.**
   행정사·금융사 소속이면 그 사실이 답변 옆에 보인다
3. **광고는 광고라고 표시한다 — 사용자의 언어로.**
   한국어로만 "광고"라고 쓰면 표시하지 않은 것과 같다

## 최대 기회이자 최대 리스크 — 요건 계산기

사용자가 영주권 점수를 계산하는 순간, **소득·학력·한국어 등급·체류기간**을 입력한다.
이것은 금융·교육 상품의 **완벽한 세그먼테이션**이다. 그리고 동시에 **민감정보**다.

**원칙: 계산은 클라이언트에서 하고 저장하지 않는다.**

- 저장하면 개인정보 문제가 생기고, 그보다 먼저 **신뢰가 무너진다**
- 저장 없이 "결과에 따라 관련 정보를 그 자리에서 보여주는 것"은 가능하다
- 프로필에 체류 연차·자격을 두더라도 **선택 입력**이고, 광고 타게팅에 쓰지 않는다

계산기 자체는 [C6 요구사항](./04-requirements.md)이고,
**틀리면 그 자체가 R3**이므로 갱신 책임자가 정해진 뒤에만 만든다.

## BD 지표 — MAU 를 보지 않는다

[05-metrics](../05-metrics.md) 의 커뮤니티 지표와 **별개 축**이다.

| 지표 | 정의 | 왜 |
| --- | --- | --- |
| **고의도 세션 비율** | 영주·대출·주거·교육 관련 세션 / 전체 | 팔 수 있는 트래픽의 비율. **총 PV 는 의미 없다** |
| **체류 연차 분포** | 3~5년차 비중 | **수익화 가능 인구.** 이 구간이 결심하고 지출한다 |
| 전환 가능 이벤트 수 | 리드가 발생할 수 있는 순간의 수 | 파트너에게 제시할 재고 |
| 리드 전환율 | 파트너 기준 성사율 | **품질**. 낮으면 단가가 깎이고 재계약이 끊긴다 |
| 파트너 재계약률 | | 한 번 팔리는 것과 사업은 다르다 |

**리드 품질이 이 사업의 전부다.** 양으로 승부하면 단가가 무너지고,
단가가 무너지면 CPM 게임으로 되돌아간다.

## 이 문서가 제품에 요구하는 것

| 요구 | 어디에 |
| --- | --- |
| 광고 슬롯을 **답변과 분리된 레이아웃**으로 설계 | 디자인 시스템 |
| 다국어 광고 표시 문구 | i18n 사전 |
| 지역 태그(시·군 단위) | [태그 설계](../10-features/05-search-and-tagging.md) — 지자체 영업의 근거이기도 하다 |
| 체류 연차·자격 **선택 입력** | 프로필 — 민감정보 취급 |
| 답변자 배지·이해관계 공개 | [평판](../10-features/04-profiles-and-reputation.md) |

## 열린 질문

- **첫 12개월 운영비를 공공 용역으로 커버할 수 있는가?** 영업 주체는 누구인가?
- 공공 용역 계약에서 **산출물 소유·재사용 권리**를 확보할 수 있는가?
  못 하면 그냥 외주다
- 비자 전문가 연결의 **법률 검토를 언제, 누가** 하는가?
- 유료 구독(B2C)을 언제 볼 것인가? 정주자는 지불 능력이 있지만
  **커뮤니티 유료화는 대체로 실패한다**
- 지자체 영업과 제품 로드맵이 충돌할 때 무엇이 이기는가? — **미리 정해 두지 않으면 용역사가 된다**
