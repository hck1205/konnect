# 03 · 관심사 — 무엇을 하러 오는가

## 관심사는 두 종류다

조사 결과가 이 서비스를 두 갈래로 갈라놓는다.

| | 1순위 어려움 | 성격 | 필요한 것 |
| --- | --- | --- | --- |
| **정보** | **언어 문제 43.4%** | 답이 존재한다. **한국어로만** 있을 뿐이다 | 검색·번역·구조화 |
| **관계** | **외로움 28.8%** | 답이 없다. **사람**이 필요하다 | 연결·안전·지속 |

**정보만 만들면 절반짜리 제품이다.** 외로움이 2위라는 사실이 그것을 말한다.
반대로 관계만 만들면 유입이 없다 — 사람은 **검색으로 들어와서** 남는다.

```
검색 유입 (정보)  ──▶  가입  ──▶  체류 (관계)  ──▶  답변자로 전환
     Q&A · 가이드              밋업 · DM · 평판
```

이 순서가 [기능 우선순위](./04-requirements.md)의 뼈대다.

### 1~4번이 하나로 묶여 있다는 점이 중요하다

유학생에게 이 넷은 **별개 주제가 아니다.**

> "학교를 옮기면 비자는? 아르바이트를 늘리면 체류에 문제가 되나?
>  기숙사를 나가면 주소 변경 신고는 언제까지?"

**정보 구조를 주제별로만 자르면 이 질문에 답할 수 없다.**
그래서 [태그](../10-features/05-search-and-tagging.md)가 **다축**이어야 한다 —
`visa:D-2` × `topic:housing` × `school:XX대` 가 동시에 걸린다.
이미 BE 가 태그 AND 필터를 지원하는 이유가 이것이다.

## 시점별 관심사 — 같은 사람의 관심이 바뀐다

| 시점 | 무엇이 급한가 | 특징 |
| --- | --- | --- |
| **도착 전 (−3~0개월)** | 비자 서류, 학교 확정, 집 구하기, 초기 비용 | **로그인 안 한 검색 유입.** 계정이 없다 |
| **직후 (0~3개월)** | 외국인등록, 통신·은행, 교통, 병원, 첫 친구 | 가장 밀도가 높다. **이탈도 여기서 난다** |
| **정착 (3개월~)** | 아르바이트, 한국어, 모임, 재계약 | 관심이 정보 → 관계로 넘어간다 |
| **전환 (졸업 전후)** | D-10, 구직, 스폰서, 계약, 세금 | **62.8%가 여기 있다.** 답변자로 전환되는 지점 |

**설계 함의**

- **도착 전 사용자는 로그인이 없다.** 읽기는 전부 공개여야 한다 (BE 가 이미 그렇다)
- 직후 3개월은 **체크리스트**의 시간이다. 검색이 아니라 **순서**가 필요하다
- 전환 시점에 **"답변자 되기"** 를 제안한다. 회로가 여기서 닫힌다

## 무엇을 하러 오는가 (Jobs)

| Job | 지금 어떻게 하고 있나 | konnect 가 나은 점 |
| --- | --- | --- |
| 한국어로만 있는 절차를 **이해한다** | 기계 번역 → 용어가 틀린다 | 원문 병기 + 사람이 쓴 설명 |
| 내 상황에 맞는지 **확인한다** | Facebook 그룹에 물어본다 → 흘러간다 | 태그로 필터된 **남는** Q&A |
| 최신인지 **확인한다** | 블로그 글의 날짜를 본다 | 신선도 표시 + 갱신 이력 |
| 겪은 사람과 **이야기한다** | 오픈채팅 → 신뢰 근거 없음 | 평판 + 1:1 쪽지 (안전장치 전제) |
| 사람을 **만난다** | 그때그때 모임 | 지역·언어 기반 연결 |

**경쟁 상대는 다른 커뮤니티 사이트가 아니라 Facebook 그룹과 오픈채팅이다.**
그쪽이 이기는 점(즉시성·자국어)과 지는 점(검색 불가·흘러감·신뢰 근거 없음)이 분명하다.
우리는 **지는 점을 공격한다** — 남고, 검색되고, 누가 썼는지 보이게.

## 정보의 위험도

비자·행정 정보는 **틀리면 피해가 실재한다.**
관심사 1·6·8·11 은 [콘텐츠 리스크 정책](../../10-domain/10-visa-immigration/03-content-and-risk-policy.md)
의 R1 영역이다. 기계 번역 전면 적용을 배제한 이유이며,
**신선도 표시와 공식 출처 링크가 선택이 아니라 요구사항**인 이유다.
