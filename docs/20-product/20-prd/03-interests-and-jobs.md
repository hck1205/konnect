# 03 · 관심사 — 무엇을 하러 오는가

> 타깃이 **정주 의도**로 바뀌면서 관심사도 통째로 바뀌었다
> ([ADR-0007](../../50-decisions/0007-settlement-intent-as-primary-axis.md)).
> 시야가 **1~2년에서 10년으로** 길어진다.

## 관심사는 두 종류다

조사 결과가 이 서비스를 두 갈래로 갈라놓는다.

| | 1순위 어려움 | 성격 | 필요한 것 |
| --- | --- | --- | --- |
| **정보** | **언어 문제 43.4%** | 답이 존재한다. **한국어로만** 있을 뿐이다 | 검색·번역·구조화 |
| **관계** | **외로움 28.8%** | 답이 없다. **사람**이 필요하다 | 연결·안전·지속 |

**정보만 만들면 절반짜리 제품이다.** 외로움이 2위라는 사실이 그것을 말한다.
반대로 관계만 만들면 유입이 없다 — 사람은 **검색으로 들어와서** 남는다.

```
검색 유입 (정보)  ──▶  가입  ──▶  체류 (관계)  ──▶  답변자로 전환
   영주권·세금·주거            지역 모임 · DM · 평판
```

정주자는 이 회로의 마지막 칸에서 **떠나지 않는다.** 그것이 이 타깃의 전부다.

### 1~5번이 하나로 묶여 있다

영주권 준비자에게 이 다섯은 **별개 주제가 아니다.**

> "소득이 얼마여야 F-2 점수가 되나? KIIP 5단계를 마치면 몇 점인가?
>  집을 사면 점수에 도움이 되나? 이직하면 그동안 쌓은 체류 기간이 초기화되나?"

**하나의 질문이 비자·소득·한국어·주거를 동시에 건드린다.**
그래서 [태그](../10-features/05-search-and-tagging.md)가 **다축**이어야 한다 —
`visa:F-2-7` × `topic:tax` × `region:안산` 이 동시에 걸린다.
BE 가 태그 AND 필터를 지원하는 이유가 이것이다.

## 시점별 관심사 — 축이 "도착 시점"이 아니라 "체류 연차"다

유학생은 도착 전/직후로 잘렸다. 정주자는 **연차**로 잘린다.

| 연차 | 무엇이 급한가 | 특징 |
| --- | --- | --- |
| **1~2년** | 체류 연장, 기본 행정, 한국어 시작 | 아직 정주를 결심하지 않았다 |
| **3~5년** | **F-2 점수 쌓기** — 소득·학력·KIIP·TOPIK | **결심하는 구간.** 검색이 폭증한다 |
| **5~7년** | **F-5 영주 신청** — 서류·요건·심사 | 실패 비용이 가장 크다 |
| **7년~** | 귀화 필기·면접, 자녀 교육, 주택 구입, 연금 | **답변자로 전환되는 구간** |

**설계 함의**

- **로그인 없이 읽을 수 있어야 한다.** 3~5년차의 검색이 주 유입이다 (BE 가 이미 그렇다)
- 3~5년 구간은 **체크리스트**의 시간이다 — 검색이 아니라 **순서와 요건 계산**이 필요하다
- 7년차 이후에 **"답변자 되기"** 를 제안한다. 회로가 여기서 닫히고, **닫힌 채로 유지된다**

## 무엇을 하러 오는가 (Jobs)

| Job | 지금 어떻게 하고 있나 | konnect 가 나은 점 |
| --- | --- | --- |
| 내가 **요건이 되는지** 계산한다 | 행정사 유료 상담 / 블로그 짜깁기 | 항목별 사례 + 태그 필터 |
| 한국어로만 있는 절차를 **이해한다** | 기계 번역 → 용어가 틀린다 | 원문 병기 + 사람이 쓴 설명 |
| **최신인지** 확인한다 | 블로그 날짜를 본다 | 신선도 표시 + 갱신 이력 |
| 같은 경로를 **지나간 사람**과 이야기한다 | 오픈채팅 → 신뢰 근거 없음 | 평판 + 1:1 쪽지 (안전장치 전제) |
| 같은 동네 사람을 **만난다** | 그때그때 모임 | 지역 기반 연결 |

**경쟁 상대는 셋이다.**

| | 이기는 점 | 지는 점 → 우리가 공격할 곳 |
| --- | --- | --- |
| Facebook 그룹 · 오픈채팅 | 즉시성, 자국어 | **흘러간다 · 검색 안 된다 · 누가 썼는지 모른다** |
| 행정사 · 유료 상담 | 정확성, 책임 | **비싸다 · 요건 되는지 미리 못 본다** |
| 다문화가족지원센터 | 무료, 통역, 대면 | **영업시간 · 대면 · 또래 경험담이 없다** |

## 정보의 위험도

영주·귀화 정보는 **틀리면 피해가 실재한다.** 관심사 1·2·3·8·10 은
[콘텐츠 리스크 정책](../../10-domain/10-visa-immigration/03-content-and-risk-policy.md)의 R1 영역이다.

그리고 정주 타깃에서는 **신선도 부담이 유학 정보보다 크다** —
영주·귀화 요건은 제도 변경이 잦은데, 답변은 몇 년씩 남는다.
**신선도 표시와 공식 출처 링크가 선택이 아니라 요구사항**인 이유다.

**우리는 정보를 주지 자문을 하지 않는다.** 이 선을 UI 에서 명시한다.
