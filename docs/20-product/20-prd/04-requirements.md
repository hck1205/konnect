# 04 · 요구사항

[03-interests](./03-interests-and-jobs.md) 의 관심사를 **만들 것**으로 옮긴다.
기능 상세는 [10-features/](../10-features/) 가 갖고 있다. 여기서는 **무엇을 왜 그 순서로** 만 정한다.

> 타깃이 **정주 의도**로 바뀌었다
> ([ADR-0007](../../50-decisions/0007-settlement-intent-as-primary-axis.md)).
> 요구사항 자체는 크게 안 바뀌지만 **무게가 옮겨간다** — 평판과 신선도가 더 중요해진다.

## 우선순위 기준

**P0 세그먼트(영주·귀화 준비자, 정착 취업자)의 검색 유입 → 체류 → 답변자 전환 회로**를
완성하는 것이 전부다. 이 회로에 기여하지 않는 기능은 아무리 좋아도 뒤로 민다.

정주 타깃에서는 **마지막 칸이 영구적**이다 — 영주권자는 떠나지 않는다.
그래서 ⑥(답한다)에 투자한 것이 가장 오래 남는다.

**제약 두 개가 더 걸린다.**

- [07-monetization](./07-monetization.md) — "팔 수 없는 것을 만들지 않는다".
  광고 슬롯 분리·지역 태그·답변자 배지가 그래서 들어온다
- [08-seo-strategy](./08-seo-strategy.md) — **SEO 가 유일한 유입 채널이다.**
  sitemap·hreflang·구조화 데이터가 "나중에"가 아니라 **Must** 인 이유다

```
① 검색으로 들어온다  ②  읽고 신뢰한다  ③  묻는다  ④  답을 받는다  ⑤  남는다  ⑥  답한다
   Must              Must              Must      Must           Should    Should
```

## Must — 이게 없으면 회로가 끊긴다

> `M`·`S`·`C` 는 **Must / Should / Could** 다 — 릴리스 단계가 아니다.
> 시간 축은 [`Phase`](../04-mvp-scope.md#릴리스-단계) 하나뿐이다.

| # | 요구사항 | 어느 고리 | 상태 |
| --- | --- | --- | --- |
| M1 | **비로그인 읽기.** 모든 콘텐츠는 로그인 없이 읽힌다 | ① | **BE 완료** (`@Public()`) |
| M2 | **다국어 UI + 언어별 URL** (`/vi/...`) | ① | **FE 완료** (en·ko·zh·vi) |
| M3 | **Q&A** — 질문·답변·채택 | ③④ | **BE 완료** |
| M4 | **다축 태그 필터** (`visa` × `topic` × `school` × `region`) | ①③ | **BE 완료** (AND 필터) |
| M5 | **키셋 페이지네이션** | ① | **BE 완료** |
| M6 | **OAuth 로그인** (비밀번호 없음) | ③ | **미구현** — 스키마만 준비됨 |
| M7 | **댓글·대댓글** | ④ | FE 컴포넌트만 (BE 미구현) |
| M8 | **신고·숨김** | ②⑤ | FE 컴포넌트만 (BE 미구현) |
| M9 | **신선도 표시** — 언제 쓰였고 언제 갱신됐나 | ② | FE 컴포넌트만 |
| M11 | **정보/자문 경계 고지** — 우리는 정보를 주지 자문을 하지 않는다 | ② | 미정 |
| M12 | **`sitemap.xml`** — 커서 페이지네이션은 크롤러가 열거하지 못한다 | ① | **미구현** |
| M13 | **`hreflang` + `canonical`** — 없으면 언어별 판이 중복으로 묶인다 | ① | **미구현** |
| M14 | **구조화 데이터 `QAPage`** | ① | **미구현** |
| M10 | **한국어 원문 병기** — 행정 용어는 원문을 함께 보인다 | ② | 패턴 미정의 |

**M9·M10·M11 이 신뢰의 전부다.** 영주·귀화 정보에서 "언제 기준인지 모르는 답"은
없는 것만 못하다 — 신청 실패는 **몇 년을 잃는 것**이다
([리스크 정책](../../10-domain/10-visa-immigration/03-content-and-risk-policy.md)).
제도 변경이 잦아 **신선도 부담이 유학 정보보다 크다.**

**M6(OAuth)이 유일한 하드 블로커다.** 지금 `/auth/login` 은 테스트 통로이고
운영에서는 404 다 — 즉 **아무도 글을 쓸 수 없다.**

## Should — 회로를 돌게 만든다

| # | 요구사항 | 근거 |
| --- | --- | --- |
| S1 | **평판·프로필** — 누가 답했는지 보인다 | **정주 타깃의 핵심 자산.** 10년차 답변자가 떠나지 않는다 |
| S2 | **이모지 리액션** | 답변자에게 돌아가는 최소 보상. 댓글보다 비용이 낮다 |
| S3 | **1:1 쪽지** | 외로움 28.8%. [ADR-0004](../../50-decisions/0004-direct-messages-with-safety-gates.md) **안전장치 7종이 전제** — C 사용자가 섞여 들어오므로 처음부터 갖춘다 |
| S4 | **알림** | 답변이 달린 걸 모르면 회로가 끊긴다 |
| S5 | **연차별 요건 체크리스트** | 3~5년차는 검색이 아니라 **요건과 순서**가 필요하다 |
| S6 | **모바일 우선 레이아웃** | 수도권 밖 43%·근로 세그먼트는 스마트폰 단독 |
| S7 | **작성 언어 태그 (`lang:`) + 가중치 정렬** | 못 읽는 글이 섞이면 피드가 쓸모없지만, 언어로 나누면 각 피드가 텅 빈다. **하드 필터가 아니라 가중치**로 시작한다 ([ADR-0010](../../50-decisions/0010-language-as-weight-not-wall.md)) |

## Could — 나중

| # | 요구사항 | 왜 지금이 아닌가 |
| --- | --- | --- |
| C1 | 가이드·위키 (구조화된 문서) | Q&A 가 먼저 쌓여야 무엇을 위키로 올릴지 안다 |
| C2 | 지역·언어 기반 밋업 | 오프라인은 안전 책임이 커진다. 사람 수가 먼저다 |
| C3 | 언어교환 매칭 | 밋업의 특수형. C2 이후 |
| C4 | 학교별 하위 커뮤니티 | 모수가 학교당 임계점을 넘어야 의미 있다 |
| C5 | **번역 보조** (요청 시, 원문 병기, 캐시, 색인 안 함) | 전면 자동번역은 R1 에서 배제됨. **언어로 나누지 않으면서 읽히게 하는 유일한 방법**이다 ([ADR-0010](../../50-decisions/0010-language-as-weight-not-wall.md)) |
| C6 | **영주권 점수 계산기** | 유입 가치가 크지만 **틀리면 그 자체가 R3** 다. 제도가 바뀌면 즉시 오답이 된다 — 갱신 책임자가 정해진 뒤에만 |

## Won't — 지금 명시적으로 안 한다

| 안 하는 것 | 이유 |
| --- | --- |
| 여행 정보 | [G 비타깃](./02-segments-and-priority.md). 포화 시장이고 이길 이유가 없다 |
| 재학 중 유학 정보 (입학·기숙사) | 정주 의도가 미정이고 관심사가 겹치지 않는다. 졸업 후 잔류 시점(D)부터 다룬다 |
| 비자 신청 대행·법률 자문 | 자격 문제이자 책임 문제. **정보와 자문의 선을 넘지 않는다** |
| 구인구직 플랫폼 | 별개 제품이다. 커뮤니티가 먼저 서야 한다 |
| 전면 자동 기계번역 | 행정 용어 오역 = 실제 피해 ([ADR-0003](../../50-decisions/0003-english-first-multilingual.md)) |
| 실명 인증 | 신원 노출이 곧 위험인 사용자가 있다 — 근로·차별, 그리고 **체류자격이 배우자에게 묶인 결혼이민자**(C) |

## 지금 상태와 다음 한 걸음

| 층 | 완료 | 비어 있음 |
| --- | --- | --- |
| **BE** | Q&A · 태그 · 페이지네이션 · 권한 · Prisma 스키마 | **OAuth** · 댓글 · 리액션 · 신고 |
| **FE** | 디자인 시스템 · i18n · 커뮤니티 컴포넌트 | **query 계층** · 화면(views) |
| **연결** | — | **BE ↔ FE 가 아직 안 붙었다** |

**다음 한 걸음은 FE query 계층이다.** 양쪽 다 각자 테스트만 통과하는 상태이고,
붙이기 전까지는 회로의 어떤 고리도 실제로 동작하지 않는다.
붙이면 `types/` 의 도메인 타입이 **실제 계약**으로 작동하고
`test:integration` 이 처음으로 의미를 갖는다.

그 다음이 **M6 OAuth** — 이것 없이는 쓰기가 영원히 불가능하다.
