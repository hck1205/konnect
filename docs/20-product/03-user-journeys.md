# 사용자 여정

## J1 · 검색으로 들어온 첫 방문자 (가장 중요)

```
Google "how to extend D-2 visa korea"
  → konnect 질문 상세 페이지 착지
  → 답을 읽음 (로그인 없이)
  → 관련 글 / 같은 태그 글로 이동
  → [전환점] 자기 상황이 조금 달라 질문하고 싶다
  → 로그인 (소셜)
  → 질문 작성 (태그 자동 제안)
```

**설계 함의**
- 상세 페이지는 **로그인 없이 완전히 읽혀야** 한다
- 상세 페이지 하단의 "관련 글"이 체류 시간을 만든다
- 로그인은 **작성 시점에만** 요구한다 (읽기 전에 벽을 세우지 않는다)
- 질문 작성 시 태그를 **자동 제안**한다 (본문에서 `D-2` 감지 → `visa:d-2` 제안)

## J2 · 답변자 (커뮤니티를 굴리는 사람)

```
알림: "내 관심 태그에 새 질문"
  → 질문 확인 → 답변 작성
  → 채택됨 → 프로필에 기록
  → 다시 방문
```

**설계 함의**
- **관심 태그 구독**이 답변자를 데려오는 유일한 장치다 (P1 알림의 핵심 용도)
- 채택·감사 표시가 유일한 보상 — 눈에 보여야 한다

## J3 · 입국 준비 중인 사용자

```
"이제 뭘 해야 하지" (막연함)
  → 체크리스트: "도착 전"
  → 항목별 가이드로 이동
  → 진행 상황 체크 (로컬 저장)
  → 막히는 항목에서 질문
```

**설계 함의**
- 체크리스트가 **가이드와 질문의 허브**가 된다
- 진행 상태는 **로컬 저장**으로 시작한다 (계정 없이도 쓸 수 있게, 민감정보 미보관)

## J4 · 고립된 사용자

```
정보는 다 찾았는데 아는 사람이 없다
  → 밋업 목록 (지역 필터)
  → 참가 신청 → 참여
  → 다시 방문
```

**설계 함의** — [안전과 신뢰](../10-domain/60-social-community/02-safety-and-trust.md)가 선결

## 여정별 우선순위

**J1 > J2 > J3 > J4.** J1이 유입을, J2가 공급을 만든다. 이 둘이 MVP의 전부다.
