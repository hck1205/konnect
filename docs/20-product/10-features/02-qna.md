# Q&A

> 우선순위 **P0** · [핵심 기능](../02-core-features.md)

## 목적

같은 문제를 먼저 겪은 사람의 답을, 다음 사람이 **검색으로** 찾게 한다.

## 모델

```
Question
  title, body, topic, tags[], author, createdAt
  acceptedAnswerId?          ← 질문자가 고른 답
Answer
  body, author, questionId, createdAt
  votes                       ← M2 이후
Comment                       ← 질문/답변에 붙는 짧은 부연
```

**답변과 댓글을 구분한다.** 답변은 "이게 답이다", 댓글은 "질문이 불명확하다"류다.
섞으면 답이 어디 있는지 안 보인다.

## 핵심 규칙

- **읽기는 비로그인 공개.** 검색 유입이 벽에 막히면 안 된다
- 작성은 로그인 필요
- 질문자만 채택할 수 있다. 채택은 **하나**
- 채택된 답변은 목록 최상단에 고정
- 자기 질문에 자기가 답하는 것은 허용한다 (스스로 해결한 뒤 남기는 것은 좋은 콘텐츠다)
- **삭제보다 정정.** 답변이 있는 질문은 삭제 대신 비공개 처리 (→ 링크가 깨지면 검색 자산이 사라진다)

## 작성 화면에서의 마찰 관리

가장 중요한 UX 지점이다. 태그를 요구하면 이탈하고, 안 받으면 매칭이 안 된다.

- 본문에서 **자동 감지**해 태그를 제안한다 (`D-2` → `visa:d-2`)
- 주제(topic)는 **필수**, 맥락 태그는 **강력 권장**
- 유사 질문을 작성 중에 보여준다 (중복 방지 + "이미 답이 있다"는 즉각적 가치)

## R1 콘텐츠 처리

주제가 비자·주거·취업이면 [리스크 정책](../../10-domain/10-visa-immigration/03-content-and-risk-policy.md)에 따라:

- 고지 배너를 답변 영역 상단에 표시
- "개인 경험" / "규정" 구분 표시
- 마지막 확인일 표시
