# 프로필과 평판

> 프로필 **P0** · 평판 **P2**

## 프로필 (P0)

### 담는 것

| 필드 | 공개 | 비고 |
| --- | --- | --- |
| 닉네임 | 공개 | 실명 요구하지 않는다 |
| 아바타 | 공개 | |
| 자기소개 | 공개 | 선택 |
| **사용 언어** | 공개 | 답변 매칭에 유용. **연결 목적에서 국적보다 낫다** ([ADR-0009](../../50-decisions/0009-nationality-display-policy.md)) |
| 작성 글 목록 | 공개 | 신뢰의 근거 |
| 가입 시점 | 공개 | 계정 나이 = 신뢰 신호 |
| 이메일 | **비공개** | 로그인용 |

### 담지 않는 것 (기본값)

**체류자격, 만료일, 학교, 직장, 실명, 국적.**
민감정보이고, 저장하는 순간 보관 책임이 생긴다
([리스크 정책](../../10-domain/10-visa-immigration/03-content-and-risk-policy.md)).

사용자가 **명시적으로 선택**하면 공개 항목으로 추가할 수 있게 하되,
기본값은 비어 있음이다. 그리고 그 값으로 자동 필터링/추천을 하지 않는다.

### 국적 표시 정책

[ADR-0009](../../50-decisions/0009-nationality-display-policy.md)가 정한다. 요약:

| 위치 | 표시 |
| --- | --- |
| 목록·피드의 작성자 | **표시하지 않는다** |
| 답변 옆 (일반 글) | **표시하지 않는다** |
| **답변 옆 (`nationality:` 태그가 붙은 글)** | **표시한다** — 공개를 선택한 경우 |
| 프로필 페이지 | 선택 공개, **기본 비공개** |
| 국기 아이콘 | **쓰지 않는다** — 정치적이고 시각적으로 너무 강하다 |

**국적은 "글의 속성"이지 "사람의 낙인"이 아니다.**
"베트남 아포스티유" 질문에서는 답변자 국적이 곧 자격이지만,
"F-2-7 점수 계산"에서는 아무 의미가 없고 편견만 만든다.

## 평판 (P2)

### 왜 나중인가

평판은 사용자 수의 함수다. 사용자가 적으면 점수가 의미를 못 갖고,
초기 기여자에게 "내 점수 낮음"이라는 부정 신호만 준다.
→ [핵심 기능](../02-core-features.md)의 설명 참고

### 설계 방향 (초안)

- 점수는 **답변 채택**과 **가이드 기여**에서 온다. 글 개수로 오르지 않는다 (양치기 방지)
- 점수를 **숫자로 크게 보여주지 않는다.** 배지/레벨 정도로 완화
- 점수를 **권한**과 연결한다 (가이드 편집, 태그 제안) — 이게 평판의 실질적 쓸모다
- 도메인별 평판을 나눌 것인가? (비자 답변을 잘한다 ≠ 주거를 잘 안다)
