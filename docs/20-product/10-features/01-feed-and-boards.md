# 피드와 게시판

> 우선순위 **P1**

## 게시판이 왜 따로 필요한가

Q&A는 **답이 있는 질문**을 위한 그릇이다. 그런데 커뮤니티에는 답이 없는 글도 필요하다:

- 후기 ("D-2 연장 다녀왔습니다")
- 토론 ("한국 생활 2년차 소회")
- 정보 공유 ("이번에 규정 바뀐 것 같아요")
- 잡담

이걸 Q&A에 넣으면 "답변 없는 질문"이 쌓여 [답변된 질문 비율](../05-metrics.md)이 망가지고,
질문 목록이 지저분해진다.

## 게시판 구성 (초안)

주제(topic)를 그대로 게시판으로 쓴다 — 새 축을 만들지 않는다.

```
Boards
├─ Visa & Stay
├─ Language
├─ School
├─ Housing & Living
├─ Work
├─ Social
└─ General / Off-topic
```

**빈 게시판을 미리 열지 않는다.** 수요가 확인된 것만 연다
(→ [캠퍼스 생활](../../10-domain/30-education/02-campus-life.md)의 같은 논의)

## 홈 피드

| 사용자 | 보여줄 것 |
| --- | --- |
| 비로그인 | 인기 질문 + 최신 글 (검색 유입자는 홈을 잘 안 본다) |
| 로그인 | 구독 태그 + 관심 주제 기반 |
